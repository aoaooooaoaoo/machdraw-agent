快速开始

本手册适用于《核反应堆物理》本科课程。学生可查教材依据、沿图谱复习，并完成需要计算、取证和修订结论的工程案例。教师可按同一道题批阅作业，复核候选错因并导出统计。

学生工作台课程图谱与案例教师主观题批阅

学生首次使用

  1. 打开学生工作台，按课程约定输入账号和密码。以后用同一账号和密码登录。
  2. 在输入框提问，或从左栏选择教材与概念溯源、课程图谱与案例、学习计划等模块。
  3. 阅读回答后，打开右侧证据卡核对教材章节。遇到算题，可查看计算卡的输入、过程与结果。

三张图谱

左栏打开「课程图谱与案例」，用页面上方的标签切换。三张图谱分别回答概念怎样相连、问题怎样递进、能力怎样通过作答体现。

图谱用途与操作
知识图谱179 个知识点、289 条关系。可按章或层级浏览，搜索术语或编号。点节点可看定义、前置、易错点、课程出处和关联案例。
问题图谱37 道问题、37 条递进关系。可按关键词或编号搜索，也可按案例查看前置题链。点问题看关联知识点、提示和递进理由。
能力图谱8 项能力。点能力看前置与后续能力，以及对应案例、综合问题和评分项。展开已有练习可查看作答证据。

沿着一个问题复习

  1. 在问题图谱搜索 Q-037，查看两份计算报告为何需要分别核对统计精度和归一口径。
  2. 点「独立估计差值的合成标准误」查看概念，再从知识点详情进入「两份计算结果的一致性复核」。
  3. 完成案例并保存自评后，打开「不确定性评估」，查看对应评分项及初判、所选材料和修订作答。

能力记录区分自评与模型建议。每个案例在当前浏览器按账号保留最近五条记录。

工程案例

在工程案例页按主题筛选或用关键词搜索。七个案例的数值为合成教学数据，概念出处可从案例或知识图谱回查。

案例练习重点
堆芯功率分布报告复核功率归一、峰均比和空间分辨率
两群模型结果差异追查按通量权重折叠响应，用对照复算追查差异
卸料燃耗统计口径审查区分整体加权均值、最高批均值和组件最大值
探测器计数记录复核统一计数口径，扣除背景并说明比较条件
停堆后两条信号的解释区分衰变释热、归一基准和仪器显示下限
温度反馈时序复盘核对时序与反馈分项，说明证据支持的归因
两份计算结果的一致性复核比较差值与标准误，分别核对统计误差和模型口径

完成一次推演

  1. 阅读题设和表格，写下初步判断、计算依据和还缺的资料。
  2. 点「记录初判，选择补充证据」，选一份材料。先看这份材料实际提供了什么。
  3. 修订结论并提交。按对应量规自评或获取模型评阅建议，可展开对照另一条证据路径。

主观题批阅

在教师端顶部点「主观题批阅」。可用内置案例，也可填写自定义题目、评分项、分值、得分要点和预设错因。

  1. 选定题目，再导入同一道题的匿名作答。可逐份录入、粘贴两列表格或导入 CSV。
  2. 用「按错答示例扫描」匹配量规里的错答短句，或用「批量模型预评」查看逐项建议。展开候选错因组，核对引文及原答卷。
  3. 可改错因名称、勾选适用作答，并把错因加入待批阅记录。检查每项分数、补充错因或评语后，点「确认并继续批阅」。
  4. 展开本题错因统计查看相关答卷，或导出本题错因报告。分母为教师确认的答卷数，同一答卷中的同一错因只计一次。

导入与演示

CSV 可使用「匿名编号,作答」或「id,answer」作表头。含换行或逗号的答案用双引号包住，答案里的双引号写成两个。每道题内匿名编号唯一。

内置案例提供「填入演示作答」，可先检查填入内容，再点「批量导入」。演示作答用于体验功能，班级统计应基于本班真实匿名作答。

模型建议与数据

主动点击模型预评时，题目、量规和对应匿名作答会发送给配置的模型。示例扫描和人工阅卷可独立使用。模型评分和归组均由教师复核。

记录备份与常见问题

记录如何保存
对话、错题及掌握度在顶栏「历史」中导出学习备份。需要恢复时从同一入口导入。
教师批阅、量规及错因记录保存在当前浏览器。从主观题批阅页导出批阅 JSON，再在目标浏览器用「恢复备份」合并。
案例初判、修订与自评可在能力图谱回看。记录按账号保存在当前浏览器，换浏览器后需重新练习。

常见操作

网页加载慢时，稍等服务唤醒。重新打开后可用顶栏连接状态确认后端是否连通。

问题图谱信息太多时，选「按案例看前置」聚焦一条题链。案例页也可先按主题过滤。

模型暂不可用时，案例可按量规自评，教师可做示例扫描与人工批阅。示例扫描的覆盖范围取决于量规中列出的短句。

拍照识别适合清晰的印刷体。公式、上下标或手写内容识别有误时，可在输入框补写关键文字。

云端服务使用临时磁盘时，重启或重新部署可能影响服务器记录。重要作业和学习数据应先从对应页面导出。
