### 1.2 工具适配器（`app/tools/`，自注册 `TOOL = ToolSpec(...)`）

统一约定：
* `TOOL.name == 文件名`（`app/tools/__init__.py` 硬校验）；
* 每个工具都接受可选 `query: str = ""`，缺省结构化参数时从 query 解析；
* 解析不到必要参数 → `ToolOutcome(ok=False, summary=..., detail="...示例...")`，**不抛异常**；
* `payload = {"result": {结构化数值}}` 供 orchestrator 组织语言。

## 5. 边界与假设（能算什么 / 不能算什么）

### 5.1 临界与扩散

**能算**：单群/修正单群（双群等效）均匀裸堆与带反射层等效裸堆的
k∞、M²、B_m²、B_g²、k_eff、ρ、P_s/P_d/P_L、平板/球/圆柱/长方体临界尺寸
（解析式 + 二分）、外推距离、反射层节省。

**不能算 / 假设**：
* 只有**单群/修正单群**，不是多群扩散或输运；没有能谱效应、没有非均匀栅元修正；
* 几何限于**均匀**平板/球/圆柱/长方体；不处理控制棒、可燃毒物、组件分区装载；
* 反射层用“等效裸堆 + 反射层节省 δ”处理，**不直接解两区扩散方程**；
  `reflector_saving_estimate` 采用满足教材两个极限的指数插值（教学估算）；
* 外推距离按真空边界 d=0.7104λtr；若用户尺寸已含外推距离，应传 d=0；
* 结果对 L²、τ、k∞ 的输入精度敏感，未做不确定度传播。

### 5.2 点堆动力学

**能算**：六组缓发中子的倒时方程 7 根、主导根/周期、瞬发跳跃、瞬发临界、
阶跃反应性后 n/n₀(t) 响应（RK4）、由功率比求平均周期。

**不能算 / 假设**：
* **点堆**：忽略空间分布；不处理氙振荡、温度反馈、控制棒价值随功率变化；
* 六组常数是 **²³⁵U 热中子裂变**（表2-3）；Pu/快谱堆需替换 `beta_groups`；
* 中子代时间 Λ 取热中子寿期 l（临界附近 l≈Λ）；默认 l=1×10⁻⁴ s；
* RK4 对刚性点堆方程需小步长，引擎自动限制步长（`dt_eff ≤ 0.5Λ/β`）并最多
  20 万步；曲线为**无反馈**响应，不能直接当事故分析结果；
* β_eff 默认 0.0065，未做缓发中子价值修正（教材 8.2 p.132 提及价值因子）。

### 5.3 燃耗与中毒

**能算**：I-135→Xe-135、Pm-149→Sm-149 的平衡浓度、恒定通量下的启动/停堆/
降功率解析解、反应性当量、碘坑 t_max/坑深/过零区间、燃耗深度、²³⁵U 消耗、
铀装载量、转换比、线性反应性模型的循环长度。

**不能算 / 假设**：
* **恒定通量**、单点（零维）燃耗链；不含空间功率分布、不含燃耗过程中通量再分布；
* 只用简化链：I→Xe（忽略 Xe 的裂变直接产生细节与中子俘获产物）、Pm→Sm
  （Sm 视为稳定核素）；其他裂变产物“打包”未实现；
* 氙/钐核数据为课程通用 ENDF/B 默认值（可覆盖），教材只给量级与公式；
* 中毒反应性当量为**一阶近似** ρ≈−Σ_p/Σ_a，未迭代临界；
* 碘坑指标依赖“停堆前剩余反应性 ρ_ex0”输入；不给定时只报 t_max/坑深；
* 线性反应性模型（LRM）假设各批料 α 相同、功率份额相同、循环末堆芯 ρ=0；
* 铀装载量为**平衡换料**简化估算，不是堆芯换料优化结果。

### 5.4 反应性、能谱、控制棒

**能算**：k↔ρ、pcm/mk/%/Δk·k⁻¹/$ 换算、温度系数（由两点反应性）、功率系数/
功率亏损、多项反应性叠加与停堆深度；Watt/Maxwell/Fermi/压水堆合成谱、
群平均截面、中子温度；控制棒积分/微分价值余弦近似、硼价值/临界硼浓度/硼浓度换算。

**不能算 / 假设**：
* 温度系数需要用户给两温度点的反应性（引擎不耦合截面/密度计算）；
* 控制棒价值余弦近似基于单群裸堆基模 φ∝cos(πz/H)、价值元∝φ²；**未考虑**
  控制棒干涉效应、通量畸变、灰棒/黑棒差异；
* 硼价值按给定 pcm/ppm **线性化**（教材 7.4.3 指出其随浓度变化）；
* 压水堆合成谱是“热 0.55 / 超热 0.30 / 快 0.15”的**教学示意加权**，
  不是输运/扩散计算得到的真实堆芯谱；
* Watt 谱参数取 U-235 标准值（a=0.965 MeV、b=2.29 MeV⁻¹），数值归一化，
  平均能量锚点校核≈2 MeV；
* 中子温度公式为教材 5.4 的工程近似，未解 slowing-down 方程。
