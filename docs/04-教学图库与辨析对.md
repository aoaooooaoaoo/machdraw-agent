## 2. 绘图规范

### 2.1 画布与坐标系

- 根元素：`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 960 640" width="100%" height="100%" role="img">`
- 固定 960 × 640；标题区 y≈40/66，正文区 y≈92~562，角注区 y≈578~620。
- 所有坐标用 1 位小数（`r()` 去尾零），控制文件体积。

### 2.2 字体与字号

- 全图继承 `font-family="Microsoft YaHei, SimHei, sans-serif"`（根 `<g>` 上一次声明）。
- 图内大标题 **24 px / 600 粗**；副标题 15 px；坐标轴标题 15 px；刻度 14 px；正文标注 13~16 px；角注 14 px。
- 上下标用 Unicode 字符（10⁻⁴、cm²、φ₁ 等），**不使用 `<tspan>`/`<foreignObject>`**，保证任何渲染器都能显示。

### 2.3 色板（统一，不得自造）

| 用途 | 色值 |
|---|---|
| 底色 | `#fbfaf7`（整张图铺底 `<rect>`） |
| 文字/轴线 | `#1f2328` |
| 主色（曲线 1、重点框） | `#2f6fb0` |
| 强调（关键结论、危险值） | `#c0392b` |
| 辅助（角注、次刻度、第二曲线） | `#7a8288` |
| 网格线 | `#e3e0da` |
| 扩展色（多曲线区分） | `#0f766e` 青、`#b45309` 橙、`#2e7d4f` 绿、`#5b4b8a` 紫 |

线宽：坐标轴 1.4、数据曲线 2.2~2.8、网格与引线 1.0~1.2、框线 1.2~1.8。

### 2.4 图注三段式（每张图强制）

1. **图内标题**：`图 <章>-<序>  <标题>`（如 `图 6-2  氙-135 浓度与停堆后的"碘坑"`）；
2. **副标题**：一句话说清"这张图在回答什么问题"；
3. **依据角注**（左下角，1~2 行）：`依据教材 第X章 §X.X p.NN 自绘`；有数值的再补一行参数/取舍说明。

另外每张图都有：坐标轴 + 单位（或流程箭头）、关键点标注（峰值/交点/阈值）、必要图例。
曲线图要求：采样点 ≥ 40（实际 200~900）、刻度取整齐值、对数轴用 10ⁿ 标注、区域可用低透明度色块分区。

### 2.5 自包含要求（硬约束）

- **禁止**：`<script>`、`@import`、`<image>`/外链图片、`xlink:href`、`@font-face`、任何 `http(s)://` 引用（`xmlns` 命名空间声明除外，它是 XML 语法不是外链）。
- 不依赖 JS、不依赖外部字体文件：浏览器缺失某个 Unicode 上标字形时会自动回退到系统字体，不影响阅读。
- 单文件可直接用 `<img src="/figures/FIG-xxx.svg">`、`<object>` 或内联到 HTML；也可离线打开。

### 2.6 校验口径（`check_figs.py`）

脚本位置：`%TEMP%\rpfigs\check_figs.py`（生成脚本同目录；如需长期保留可移入 `scripts/`）。逐文件检查：

1. `xml.etree.ElementTree` 能解析、根元素为 `{http://www.w3.org/2000/svg}svg`；
2. `viewBox` 存在且等于 `0 0 960 640`；
3. `<text>` 元素 ≥ 8 个；
4. 不含 `script/@import/xlink:href/image/foreignObject/@font-face`；
5. 无 `href/src` 指向 `http(s)://`、`//`、`file:` 的属性，无 `url(http…)`；
6. 无 `nan / inf / None` 等非法坐标或文本（曲线越界时按 ylim 裁剪而不是产生 nan）；
7. 字体集合必须 ⊆ `{Microsoft YaHei, SimHei, sans-serif}`；
8. 越界粗检：文字/图元估算包围盒是否超出画布；
9. 文字重叠粗检：按字号估算包围盒，两两相交面积 > 42% 报警；
10. `marker-end`/`marker-start` 引用的 id 必须存在。

> 由于本机没有可用的无头浏览器/`libcairo`，另写了一个只支持本工程 SVG 子集的 **PIL 预览渲染器**
> （`preview.py`：rect/line/circle/ellipse/path(M,L,Z)/text/rotate/虚线/箭头），
> 把 32 张图渲成 PNG 后逐张目检排版（含 5% 透明阴影、二轴、对数轴、中文换行），
> 这也是发现"曲线越界画到画布外""碘曲线冲出坐标区""标注压线"等问题的手段。

## 3. 与前端 / 后端的挂接

### 3.1 `figures.jsonl` 字段（SPEC §3.5）

```json
{"figure_id": "FIG-XENON-CURVE", "file": "FIG-XENON-CURVE.svg",
 "title": "氙-135 浓度、剩余反应性与停堆碘坑", "chapter": "第六章 燃耗与中毒",
 "kp_ids": ["KP-BURN-00X", "..."], "structure_tags": ["氙毒","碘坑","停堆瞬变","强迫停堆时间","剩余反应性","最大碘坑时间"],
 "caption": "……（图注，写清图上有什么、关键结论）", "license": "自绘",
 "source": "依据教材 第6章 6.2.1 节 p.103~106 与课件第6章自绘"}
```

- `file` 相对 `kb/figures/`；`license` 恒为 `"自绘"`；`source` 必填（含章节页码）。
- `kp_ids` 由 `scripts/link_figures.py` 依据 `_link_terms.json` 回填（每图最多 4 个，当前每图 3 个）。

### 3.2 后端接口

| 位置 | 内容 |
|---|---|
| `apps/api/app/state.py` | `AppState.figures` / `.pairs` 在启动时装载 `figures.jsonl` / `pairs.jsonl`；缺文件时进 `warnings` |
| `state.figures_for(kp_ids, chapter="", limit=2)` | 先按 `kp_ids` 交集命中，命不中再按 `chapter` 前 6 字兜底；返回图 dict 列表 |
| `GET /api/figures` | `{"figures": [...], "total": N}`，每项含 `file` |
| `GET /api/pairs` | `{"pairs": [...], "total": N}` |
| `app.mount("/figures", StaticFiles(...))` | 前端用 `/figures/FIG-xxx.svg`（或 `pairs/PAIR-xxx.svg`）直接取 SVG |
| `GET /api/health` | 报告 `figures=N pairs=M` 装载数；装载失败会出现在 `warnings` |

### 3.3 证据卡 / 检索结果如何挂图

`apps/api/app/tools/kb_search.py` 在组装证据卡时：

```python
figures = []
for f in st.figures_for(h.get("kp_ids") or [], chapter=h.get("section", "")):
    if f.get("figure_id") not in {x.get("figure_id") for x in figures}:
        figures.append(f)
    if len(figures) >= 3:
        break
```

即：**先按命中分块的 `kp_ids` 找图，再用分块所属章名兜底，最多带 3 张**，随 `EvidenceCard.figures` 一起返回；
前端证据卡（`evidence` 画布）在正文旁按 `file` 渲染缩略图，点击放大。
`kg_lookup` 查询知识点时同理可用 `figures_for([kp_id])` 取该知识点的配图。

> 设计意图：**图不单独检索，永远跟着知识点走**。所以 `_link_terms.json` 的术语选择要贴 KP 的
> `term/aliases`，而不是贴图的标题——否则回填命中率会掉。

### 3.4 `_link_terms.json` → 回填流程

```json
{"FIG-XENON-CURVE": ["氙毒", "碘坑", "碘坑深度", "最大碘坑时间", "强迫停堆时间", "允许停堆时间", "剩余反应性", "停堆", "氙振荡"]}
```

`scripts/link_figures.py` 的匹配规则（从严到宽）：
1. KP 的 `term` 与术语**完全相等**；
2. KP 的 `aliases` 里含该术语；
3. `term/aliases` 与术语互相包含（长度 ≥3 才允许）；
4. 术语是 KP `term` 的子串且长度 ≥4。

每图按优先级去重取前 4 个。命令：

```bash
python scripts/link_figures.py          # 原地重写 figures.jsonl / pairs.jsonl，打印命中统计
```

写图的人只维护 `_link_terms.json`（术语清单），**不猜 `kp_id`**；KP 改名后重跑一次即可对齐。

## 5. 维护方法：新增一张教学图

1. **画图**：在 `kb/figures/` 新建 `FIG-<大写TAG>.svg`。可复制现有图改（保持 `viewBox`、色板、字体、三段式图注），
   曲线用 ≥40 个采样点、刻度取整齐值；图注写 `依据教材 第X章 §X.X p.NN 自绘`。
2. **登记**：在 `kb/figures/figures.jsonl` 追加一行（`kp_ids` 先留 `[]`，`license:"自绘"`，`source` 写依据）。
3. **写术语**：在 `kb/figures/_link_terms.json` 加 `"FIG-<TAG>": ["术语1", "术语2", ...]`（贴 KP 的 `term/aliases`）。
4. **回填**：`python scripts/link_figures.py` → `kp_ids` 自动填好，并打印每个图命中的 KP。
5. **校验**：`python %TEMP%\rpfigs\check_figs.py`（或把脚本移入 `scripts/check_figures.py`）确认 0 error；
   有条件再用浏览器/预览器目检一次。
6. **生效**：后端 `AppState` 在启动时装载 `figures.jsonl`，**重启后端进程**即生效（`uvicorn app.main:app`）；
   若只想热更新，可调用内部的 KB 重载（`state` 的装载函数）而无需改代码。前端 `npm run dev` 下刷新页面即可看到新图。

> 改数值时只改生成脚本里的常量（截面/产额/衰变常数等），重跑脚本让曲线与标注一起更新——
> **不要手改 SVG 里的数字**，否则图注与曲线会不一致。
