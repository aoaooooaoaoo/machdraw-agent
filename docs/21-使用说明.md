## 0. 一句话

这是一门**核反应堆物理**课程的 AI 助教：答案可回翻教材原文、计算由确定性引擎给出、概念图/题卡/错题本都会自动生成；教师端可以看全班的掌握度和错题根因。

## 1. 学生端：5 分钟上手

### 1.1 登录

打开网址 → 输入**学号/姓名**作为账号、任意密码 →「进入工作台」。

- 首次输入会**自动建号**；之后用同一账号+密码可找回个人记录。
- 账号记录存在服务器 SQLite；**免费部署重启会清空**，重要数据请用「历史 → 导出备份」（见 1.12）。

### 1.2 界面（三栏）

| 区域 | 作用 |
|---|---|
| 顶栏 | 连接状态、当前模型、**笔记/历史/复习/搜索**、主题切换、意见反馈、退出 |
| 左栏 | 10 个模块导航 + 知识库统计 + 门控阈值 |
| 中栏 | 对话：消息、思考过程、工具卡、Markdown/公式 |
| 右栏 | 画布：证据卡 / 计算卡 / 曲线 / 对比 / 批注 / 题卡 / 错题本 / 知识图谱 |
| 底栏 | 消息数、证据段数、覆盖率、耗时、SSE 状态 |

### 1.3 怎么提问

直接在底部输入框写自然语言，例如：

- 「什么是缓发中子？为什么它对反应堆控制很重要？」
- 「k_eff=1.05 时反应性是多少 pcm？」
- 「考我一道题」
- 「点堆动力学依赖哪些前置知识？」

发送后注意三件事：

1. **工具卡**：显示 Agent 调用了哪个工具（检索/计算/出题/图谱），点开可看参数与返回；
2. **证据卡**：右栏每段证据带「文档 · 章节 · chunk_id · 相关度」，可展开全文、围绕此段追问；
3. **公式**：回答里的 LaTeX 会渲染成分式；如果显示不出来，说明模型没按格式输出，可点「重新回答」。

### 1.4 10 个模块怎么选

| 模块 | 适合问什么 | 主要产出 |
|---|---|---|
| 全局对话 | 不确定归哪类的问题 | 自动路由 + 证据/计算 |
| 教材与概念溯源 | 定义、原理、教材原文 | 证据卡 + 出处 |
| 临界与扩散计算 | k∞、M²、B²、临界尺寸、反射层 | 计算卡（确定性引擎） |
| 动力学与反应性 | 缓发中子、周期、瞬发临界、$ 换算 | 曲线 + 计算卡 |
| 燃耗与中毒 | 氙/钐中毒、碘坑、燃耗深度 | 曲线 + 计算卡 |
| 概念辨析 | 快/热群、扩散/输运、正/负温度系数 | 对比表 + 随堂题 |
| 课程图谱与案例 | 前置关系、问题递进、能力和工程应用 | 知识图谱、问题图谱、能力图谱、案例练习 |
| **学习计划** | 今天学什么、复习什么 | 今日任务 + 下一步建议 |
| 错题与计算批改 | 错题六步诊改、错题本 | 批注 + 错题本 |
| 费曼追问 | 用自己的话讲一遍 | 多轮追问 + 评价 |

### 1.5 画布操作

- 右栏可**全屏查看**（Esc 退出）、**收起**；
- 右上角按钮：**导出 Markdown**、**打印/另存 PDF**；
- 题卡：先自己想 →「我先想想」看解析 → 可「自动判分」或自评「我会了/还不会」；
- 证据卡：点「围绕此段追问」把原文带进输入框；
- 一次回答可能同时有多个画布，用顶部标签切换（如 quiz / evidence）。

### 1.6 知识图谱

左栏「课程图谱与案例」：

- 10 章按颜色分簇的**深色星图**，节点大小=关联数，中心点=学习状态（未学/在学/已掌握/需复习）；
- 搜索框可搜知识点或 kp_id；点章名 pill 聚焦该章；点节点看右侧详情（定义、要点、易错、前置、后继）；
- 悬停高亮一跳邻居；滚轮缩放、拖拽平移；
- 可切「浅色/星图」主题；层级 L1–L4 与章筛选可隐藏。
- **知识图谱**的知识点详情可进入关联课程问题、工程案例及案例考查的能力。
- **问题图谱**按三层递进展示 37 道问题，可按关键词搜索，也可选定案例查看前置问题链。打开问题详情可以看连线依据，跳到关联知识点、案例和能力。
- **能力图谱**包含 8 项能力，新增量纲与测量口径、时序与反馈辨析、不确定性评估。可沿前置和后续能力查看案例、综合问题和分项评分，并展开初判、取证和修订记录。每个案例在当前浏览器按账号保留最近五条记录，标明自评或模型建议。
- **工程案例**共 7 个，可按主题或关键词筛选。在功率分布、群常数和卸料燃耗三个案例的基础上，加入探测器计数、停堆后信号、温度反馈时序和计算结果一致性。学生先写初判，再选择补充材料，最后依据实际获得的证据修订结论。提交后可对照另一条证据路径，并按所选路径的量规自评或请求模型建议。

### 1.7 做题、判分与掌握度

1. 输入「考我一道题」或在概念辨析/错题模块里出题；
2. 题卡先自己写答案（输入框在解析下方）；
3. 「提交判分」→ 星火对照参考答案给 **分数 + 评语 + 漏掉的点 + 参考答案**；
4. 或展开解析后自评「我会了 / 还不会」；
5. 判分/自评会回写**掌握度**：图谱节点变色、学习计划更新、不及格自动进错题本。

> 说明：题库来自扫描件，题面偶有 OCR 错字；自动判分约需 10–15 秒（星火模型）。

### 1.8 学习计划

左栏「学习计划」：

- **今日任务**：到期复习（FSRS-lite，需复习 1 天 / <75% 3 天 / ≥75% 7 天）；
- **下一步建议**：按图谱前置关系推荐「前置已掌握」的知识点；
- 点「去复习 / 去学习」自动切到对应模块并发起提问；
- 顶栏「复习」也能随时打开到期复习抽屉。

### 1.9 费曼 / 概念辨析 / 错题批改

- **费曼追问**：把某个概念讲给 Agent 听，它会连续追问，最后给对照评价；
- **概念辨析**：给出成对图/对照表，让你找差异；
- **错题与计算批改**：按「原题→错误作答→根因→溯源→正解→避坑」六步拆解；输入「我的错题本」可查看记录。

### 1.10 语音、拍照与公式

- **语音输入**：输入框麦克风按钮（Chrome/Edge，需麦克风权限），识别结果进入草稿；
- **朗读**：助手消息操作条「朗读/停止」；
- **拍题**：输入框回形针 → 选图/拍照（手机可调后置摄像头）→ 发送时自动 OCR，识别文字拼进问题；
- **OCR 限制**：印刷体/截图效果好；手写、复杂公式上下标不稳，建议补文字描述。

### 1.11 便签、历史、命令面板、主题

- **便签**：顶栏「笔记」→ 浮层卡片，拖动标题栏移动；支持多张、颜色、折叠、Markdown/公式预览，按账号自动保存；
- **历史**：顶栏「历史」→ 后端按天保存的会话，点一条恢复消息 + 最近画布；
- **命令面板**：`Ctrl/⌘ + K`，搜索模块/问题/操作（新会话、历史、复习、便签、教师端、复制运行信息）；
- **主题**：顶栏太阳/月亮，深浅色切换并记住。

### 1.12 数据与备份（重要）

- 对话、画布、便签、掌握度镜像会自动存在浏览器（按账号）；
- **服务器**（Render 免费档）重启/重部署会清空 SQLite（账号、历史、掌握度、错题本服务端部分）；
- 换设备或重启前：顶栏「历史」→ 底部 **「导出备份」**（JSON）；
- 新设备/恢复：同一位置 **「导入备份」**，刷新后生效；
- 备份只增不减、错题按题面+trace 去重。

## 2. 教师端（/admin）

### 2.1 主观题批阅

从教师端顶部进入「主观题批阅」。可选课程案例，也可新建题目、分项分值、得分要点和预设错因。

1. 输入匿名编号和作答，从表格批量粘贴两列，或导入带「匿名编号,作答」表头的 CSV。含换行的 CSV 作答用双引号包住。「填入演示作答」会把合成练习样卷填入输入框，提交前可查看。
2. 按同一道题选择「按错答示例扫描」或「批量模型预评」。示例扫描匹配量规中明确列出的短句。模型预评可提出新错因，并附逐项分数和作答引文。自定义量规可用「错因｜错答原话」添加本题的匹配示例。
3. 展开候选组，查看证据和原答卷，改名并勾选适用作答。选中的错因会进入待确认批阅。点击「确认并继续批阅」后，才计入本题统计。百分比的分母是已确认作答数，同一作答中的同一错因只计一次。统计可点回原答卷，也可导出本题错因报告。
4. 批阅数据保存在当前浏览器，可导出 JSON 备份。恢复会合并匿名编号，已有的确认记录优先。主动请求单份模型建议或批量模型预评时，会把题目、量规和相应匿名作答发送给所配置的模型。

评分和工作流借鉴 [PrairieLearn 的按题批阅与评分量规](https://github.com/PrairieLearn/PrairieLearn/blob/master/docs/manualGrading/index.md)。候选归组参考 [Powergrading 的作答分组](https://aclanthology.org/Q13-1032/)，本项目按量规错因编号或候选标签归组。能力结构和证据分别参考 [OpenCASE](https://github.com/1EdTech/OpenCASE) 与 [Moodle](https://docs.moodle.org/402/en/Competencies)。案例取证路径参考 [H5P Branching Scenario](https://h5p.org/branching-scenario)。

### 2.2 学情与语料

打开 <https://reactor-physics-agent.onrender.com/admin>，可看：

- KPI：语料块数/文档/图谱规模/账号/消息/拒答率/平均覆盖率；
- 学情看板：事件埋点、门控统计；
- 错题根因分布 + 最近错题；
- **学习者模型**：各状态人数 + 最需要关注的知识点；
- 语料清单（点行展开章节）、待教师复核（文本里带"待核/存疑/以标准表为准"的段落）、账号列表。

> 教师端没有单独登录鉴权，**仅限内部教学使用**；公网部署建议加访问控制/内网访问。

## 4. 常见问题

**Q1：为什么回答"知识库未收录"？**
A：检索覆盖率低于门控阈值 τ=0.40，系统按课程范围**主动拒答**，不是错。换课程里的术语再问（如"有效增殖系数、缓发中子、多普勒展宽、点氙中毒、燃耗深度"）。

**Q2：为什么有时回答很慢？**
A：真实模型（星火）首答约 10–18 秒；相同问题会命中语义缓存。计算/出题类由确定性工具给出，通常毫秒级。

**Q3：公式显示成代码/不渲染？**
A：回答没有按 LaTeX 输出。点「重新回答」；本系统提示词已要求用 `$...$` / `$$...$$`。

**Q4：拍题识别不准？**
A：OCR 对印刷体最佳；手写/复杂公式有限。尽量拍正、清晰、光线均匀，或在输入框补一句文字描述。

**Q5：手机上怎么用？**
A：浏览器打开后可用底部「模块/对话/画布/图谱」导航；支持"添加到主屏幕"（PWA），但**没有离线缓存**，断网不能用。

**Q6：数据丢了怎么办？**
A：如果之前导出过备份，用「历史 → 导入备份」恢复；没导出则免费档重启后无法找回，建议每周导出一次。

**Q7：判分 / 掌握度不准？**
A：判分基于参考答案+评分点，可能受 OCR 题面/表述差异影响；以「对照参考答案」为准，可自评修正。

**Q8：能离线用吗？**
A：不能。需要联网访问 Render；本地部署可完全离线（见 `DEPLOY.md`）。

## 5. 已知限制（如实说）

- Render 免费档：15 分钟闲置休眠（首访约 40–60 秒唤醒）、**无持久盘**（数据会重置）；
- 只有 Spark `spark-x2.6-4b` 一个文本模型，**无多模态视觉**；拍题靠 tesseract OCR；
- 题库 112 题的 kp 标注是自动匹配，个别题目可能偏差；
- 自动判分约 10–15 秒，复杂主观题建议对照参考答案；
- 历史/掌握度/便签跨设备不同步（靠导出/导入）；
- 教师端无鉴权，公网仅建议内部使用。
