## 3. 关键质量结论（决定语料方案）

1. **印刷清样 PDF 的文字层不可用**：内嵌字体缺 ToUnicode/CMap，pymupdf 直读得到的是乱码（255 页只有 29 个汉字）。**不取其文字、不引其页码。**
2. **教材原稿 DOC 是唯一可靠的全书文字源**：Word97 OLE + piece table 解析成功，15.4 万字符（其中 9.36 万汉字），含完整目录、节号、页码、公式（部分公式以字符拼写）、例题与章末习题。**全项目引教材页码一律以该文件目录中的「书内页码」为准。**
3. **10 章 PPT 的正文可用，但公式/插图是图片**（每章 72~192 个内嵌图片，多为 WMF/EMF 公式对象）：适合做"章节框架 + 页面级引用"，不适合作为公式/数值来源。
4. **ZIP 内 PDF 版课件与 pptx 是同一批课件的不同修订**（相似度 0.15~0.78），文字层可用（每章 1.6~3.2 千汉字）。作为**补充语料**，不重复计入。
5. **两本扫描 PDF（198 页 + 172 页）无文字层**：可用 tesseract 渲染 OCR，但正确率与工作量不划算，本版**只作背景参考**，不作为知识条目依据。
6. **PPT 内嵌图片 793 个 / 63.6 MB** 已导出到 `working/media/`：其中 `.wmf/.emf` 是公式矢量对象（不可直接当插图），`.png/.jpeg` 可用于教学图库的视觉参考。**教学图库最终仍以自绘 SVG 为准**（可检索、可标注、无版权风险），不直接复用课件截图。

## 7. 版权与使用边界

- 教材、课件、复习笔记、习题解答均为**用户提供的课程内部资料**；习题入库标 `internal_only: true`，仅限内部教研，对外发布须换源或获授权。
- 知识条目、图谱、教学图库、标准整理为**自写表述**，可对外使用；引用教材/标准时注明出处。
- 本工程不复制教材原文长段，不做扫描件再分发。
