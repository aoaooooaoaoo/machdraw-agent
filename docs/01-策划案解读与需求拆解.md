# 01 · 策划案解读与需求拆解

> 来源：`机械制图agent策划案.pptx`（16 页，作者：杨馨渝）
> 解读目的：把"策划案里写了什么"翻译成"代码要交付什么"，并标出策划案没写、但实现时必须补的空白。

---

## 一、一句话定位

做一个**"懂国标、通空间、能判图"的多模态 AI 助教**：以机械制图课程知识库为唯一事实来源，用对话 + 3D/2D 联动可视化 + 知识图谱学情诊断，解决"空间想象力断层、大班反馈滞后、国标规范繁琐"三个教学痛点。

对标对象：西安交通大学《材料物理实验教学Agent》（材料实验Agent）的**六大模块**，做同构重映射 + 两个新增模块。

## 三、模块级需求（策划案 P6–P7 映射表逐条解读）

策划案把对标作品的 6 个模块重映射为机械制图的 6 个模块，再加 2 个新增，合计 **8 个模块**。

### 3.1 全局对话入口
- 功能：文本 + 语音输入，统一调度各子模块。
- 策划案技术方案：LLM 意图识别 + 路由分发。
- **实现要点**：这是"总入口/路由器"，本身不产出教学内容，负责把用户话语判到某个模块并带参数过去（对标作品用 ReAct 工具总线实现，见 02 文档）。

### 3.2 国标与概念溯源（对标"知识库 RAG"）
- 功能：问"内螺纹剖视图画法"，要精准答出"大径细实线、小径粗实线"，并**附教材与 GB/T 4459 原文截图**。
- 策划案技术方案：教材 PDF / 国标文档向量化（Milvus）+ 强制 RAG 约束防幻觉。
- **实现要点**：
  - "原文截图"意味着证据链要能**定位到页码并回渲图像**，不只是返回文本片段——这是比对标作品更强的要求（对标作品只给文本段落 + 匹配度）。
  - "强制 RAG 约束防幻觉"= 知识边界门控，对标作品的做法是 IDF 加权关键词覆盖率门控 + 提示词约束（细节见 02 文档），**可直接复用**。

### 3.3 剖视与投影辨析（对标"金相组织辨析"）
- 功能：给"阶梯剖/旋转剖/局部剖"或"相贯线/截交线"的**典型对比图**，对话中考察学生找差异。
- 策划案技术方案：图像比对 + 图谱节点知识推流。
- **实现要点**：本质是"成对图 + 差异点标注 + 追问式测验"。关键资产是**成对对比图库**（每对图要有差异点坐标/描述），这块 PPT 没说从哪来。

### 3.4 智能找茬与错题本（对标"材料科学错题集"）
- 功能两条腿：
  1. **视觉批改**：学生拍照上传手绘图，AI 圈出"漏标尺寸""虚实线混淆"等错误。
  2. **错题归纳**：自动收录"尺寸链封闭"等易错题。
- 策划案技术方案：视觉大模型（GPT-4o / Qwen-VL）+ 图像处理算法。
- **实现要点与风险**：
  - 手绘图批改是**最难落地**的一块。视觉大模型对"线条粗细是否符合 GB/T""剖面线角度是否 45°""中心线是否漏画"的判断并不可靠，需要**传统 CV 做几何校验**（直线检测、线宽测量、角度测量、圆/圆弧拟合）+ 视觉模型做语义理解，二者结合。
  - "圈出错误"要求返回**坐标 + 错误类型**，不是一句文字点评。这需要一个结构化的批改结果契约。
  - 错题本需要题目 ID 体系，否则无法做"再练一遍"。

### 3.5 形体重构与费曼追问（对标"费曼追问"）
- 功能：学生描述形体（"底部圆柱，顶部燕尾槽"），Agent 反问（"左侧是否有通孔？圆柱与筋板是否共面？"），倒逼完善空间逻辑。
- 策划案技术方案：语音/文本解析 + 3D 拓扑结构匹配。
- **实现要点**："3D 拓扑结构匹配"是策划案里最容易写、最难做的一条：需要把自然语言形体描述解析成**特征树**（CSG/特征序列），再判断描述是否完备/自洽。工程上更现实的做法是：预置若干目标形体，每个形体带"必答特征清单"，Agent 按清单缺口追问（缺哪问哪），最后按覆盖率打分。

### 3.6 虚拟画图教练（新增）
- 功能：动态演示"外切圆弧连接"步骤：找圆心 → 找切点 → 画弧。
- 策划案技术方案：动画分步渲染 + 步骤同步解析。
- **实现要点**：这是**纯 2D 作图过程动画**，是所有模块里性价比最高的一个（技术简单、演示效果强）。可选实现：SVG/Canvas 分步脚本 + 几何计算（求圆心、切点都是确定的解析几何）。

### 3.7 公差与配合侦探（新增）
- 功能：输入"Φ30 H7/k6"，解析基孔制过盈配合，并结合加工工艺（车削/磨削）解释粗糙度要求。
- 策划案技术方案：国标公差表数据库结构化查询。
- **实现要点**：
  - 底料来自 GB/T 1800.1/1800.2（极限与配合）——需要把公差表**结构化入库**（孔/轴基本偏差表 + IT 等级表），不能靠 LLM 背。
  - 计算内容：极限尺寸、配合公差、最大/最小间隙或过盈、基孔制/基轴制判定、配合类型判定。
  - 这部分**规则确定、可 100% 算准**，是对标"物理建模约束"的对应物，也是最容易做出"零幻觉"效果的地方。

## 四、3D 可视化模块（策划案 P9）逐条解读

> 标题：**两屏联动（3D 实体与 2D 三视图绝对同步）**

1. **技术底层**：Three.js 渲染 + OpenCascade.js（OCCT）几何引擎，支持 STEP/IGES 标准格式。
   - → 意味着要有 **WASM 侧几何内核**，不是纯前端画个盒子。OCCT 的 `HLRBRep_Algo`（隐藏线消除投影）正好是"3D → 精确三视图"的工业级解法，这是这个模块能成立的技术关键。
2. **界面布局**：左对话区；右主视窗，上部 3D 正交模型，下部动态生成的三视图投影面。
   - → 右栏是"上下分屏"，与对标作品"右栏单画布"不同，需要做分屏容器。
3. **四大核心交互**（实际列了 5 条）：
   - **投影辅助线联动**：旋转/平移/缩放 → 三视图同步更新，并用彩色虚线勾勒"长对正、高平齐、宽相等"。
   - **动态剖切沙盒**：可拖拽假想剖切面 → 全剖/半剖效果 + 2D 视图同步生成剖面线，解释"肋板纵剖不画剖面线"等易错点。
   - **标准件比例画法生成器**：输入"M10 螺栓" → 3D 生成 + 2D 展示比例画法关系。
   - **装配体爆炸与拆装**：减速器等经典模型一键爆炸；点零件高亮显示明细表序号、配合公差、定位关系。
   - **2D 转 3D 升维沙盒**：画三视图草图 → 拉伸/旋转 → 生成 3D 模型供验证。

**风险排序（我的判断）**：
| 交互 | 技术难度 | 说明 |
|---|---|---|
| 投影辅助线联动 / 三视图同步 | 中 | OCCT HLR 可解；难点在"三视图与 3D 视口坐标系对应"和实时性能 |
| 动态剖切 + 剖面线 | 中高 | 剖切用 clipping plane（视觉近似）；但"2D 剖面线"需要真正的截面求交 + 剖面域填充 |
| 标准件比例画法生成器 | 低 | 螺纹/螺栓比例画法是查表 + 参数化，2D/3D 都可参数生成 |
| 装配体爆炸拆装 | 低中 | 需要一个有层级/装配关系的模型，爆炸只是沿方向平移动画 |
| **2D 转 3D 升维沙盒** | **极高** | 从手绘三视图恢复 3D 是逆问题（多解、需人工约束），对标作品也没有做。建议降级为"选图 → 拉伸/旋转参数化重建"或"读图 → 正误判定" |

## 五、知识图谱（策划案 P11）解读

结构："一核心、两主线、双分支"

```
一级（核心）：空间形体与工程表达
├─ A 线·形体表达链：投影基础 → 基本体 → 截交与相贯 → 组合体 → 剖视与断面
├─ B 线·工程规范链：制图国标 → 尺寸标注 → 技术要求（粗糙度/形位公差） → 标准件与装配
└─ 三级（应用分支）：① 零件图表达（工艺结构/识读） ② 装配图表达（配合关系/装配工艺）
```

- **边（关系）两类**：
  - 前置依赖边（如"剖视图"依赖"虚线隐藏"+"剖切平面"；"相贯线"依赖"回转体投影"）
  - 易混淆对比边（"截交线"↔"相贯线"；"局部剖"↔"半剖"）
- **与 Agent 联动**：
  - 答错 → 图谱亮红灯 → 沿前置依赖边推送复习微课
  - 颜色状态：未学(灰) / 正在学(黄) / 已掌握(绿) / 需复习(红)

**解读**：
- 对标作品是 71 节点 / 105 关系 / 五级，并且有"知识图谱 + 问题图谱"双模式（第二模式按布鲁姆认知层级三层递进排布问题）。**策划案只写了知识图谱，没写问题图谱**——但"问题图谱"恰恰是评审最容易看懂的那部分，建议补。
- 策划案说"双分支"（零件图、装配图），但前面说"一核心、两主线、双分支"，层级命名上"一级/二级/三级"与"双分支"未对齐，实现时需要一份正式节点表来定稿。

## 六、资源库与授权（P13）解读

四类物料：
1. **教材与图库版权授权（西交版）**：理论知识库 / 3D 模型 / 尺寸标注画法 / 往年真题精选 / 最严格标准规定。
2. **GB/T 国家标准数据库**：采购或整理现行《技术制图》《机械制图》全套国标文本（举例 GB/T 4457.4-2002 图线、GB/T 4458.4-2003 尺寸注法）。
3. **3D 资产模型库**：基础立体、截切与相贯、标准件、经典装配体（台虎钳、减速器），格式 **GLTF/GLB**。
4. **算力与 API**：LLM API（DeepSeek R4 / Qwen 3）+ 云端服务器（WebGL 渲染 + WebRTC 语音流）。

**解读与提醒**：
- 第 1 类是**授权依赖**，不是代码问题：没有授权就不能上线。开发阶段必须用**自建/开源替代料**先把链路跑通（例如自绘标准图例、公开国标文本、自建模型），把"换料"做成配置项。
- "支持 STEP/IGES"（P9）与"资产用 GLTF/GLB"（P13）是两套格式：**STEP/IGES 是输入（学生/教学用模型），GLTF/GLB 是渲染资产**。系统需要一条 `STEP → (OCCT 解析) → 三视图 + 轻量化 GLB` 的转换管线。

## 七、开发规划（P15）解读

- **一期 MVP（1–2 月）**：知识图谱 + 全局对话 + 国标 RAG 溯源 + 基础 3D 旋转及三视图联动。验收 = 验证大模型回答准确率。
- **二期（3–4 月）**：动态剖切沙盒 + 智能找茬（拍照批改）+ 错题集。接入视觉模型，完善图谱学情推送。
- **三期（5–6 月）**：装配体爆炸拆装 + 2D 转 3D 沙盒 + 费曼追问。学生端/教师端 UI/UX 打磨。

**解读**：
- 节奏合理，但**一期把"3D 三视图联动"放在 MVP 里是最大的排期风险**（OCCT/HLR 链路一旦调不通，MVP 就拖住）。建议一期内把 3D 拆成"先静态预生成三视图 + 联动高亮"，把实时 HLR 放到二期。
- 三期才做费曼追问偏晚：费曼追问是纯文本 + 提示词工程，成本低、演示效果强，建议提到二期甚至一期尾。
- 三期"2D 转 3D 沙盒"建议直接降级（见第四节风险表）。

## 八、策划案没写、但实现必须补的空白（Gap List）

按"不补就会卡住开发"的程度排序：

| # | 空白 | 影响 | 建议补法 |
|---|---|---|---|
| G1 | **没有系统架构图与数据契约** | 8 个模块无法并行开发 | 直接借对标作品的"契约驱动可插拔模块 + 七类事件流"（见 02 文档），这是最省事的架构决策 |
| G2 | **没有 UI 原型/线框图** | 前端无法开工；两屏联动布局（3D 上/三视图下）没说清比例与交互 | 先出低保真原型（三栏 + 右下分屏），用对标作品三栏工作台做基线 |
| G3 | **没有知识库物料清单（实际文件）** | RAG 无米下锅 | 明确"教材章节 + 国标条目 + 课件 + 真题"的落地文件与切分方案 |
| G4 | **没有题库与题目元数据结构** | 错题本、辨析题、判分全靠它 | 定义 `题目/答案/知识点/难度/图` 元数据 schema；真题来源需授权 |
| G5 | **没有评估方案** | 无法证明"回答准确率"（一期唯一验收项） | 照搬对标作品的探针法：N 道课内 + M 道课外探针，统计覆盖率门控、Hit@3、拒答率 |
| G6 | **没有 3D 资产的制作与授权方案** | 装配体爆炸拆装无模型可用 | 先用开源 CAD 模型（台虎钳/减速器）做 demo，标注许可 |
| G7 | **没有教师端功能定义** | 三期"双端"无处落地 | 教师端最小集：语料维护、错题统计、学情看板、内容审核 |
| G8 | **没有视觉批改的标注规范** | AI 找茬无法评估好坏 | 定义错误码表（漏线/线型错/线宽错/剖面线方向/漏标尺寸/尺寸基准错…）与标注样本 |
| G9 | **没有成本与合规边界** | 视觉模型按图计费，成本失控 | 前端先做图像预处理/降采样；批改走"CV 预校验 + VLM 复核"省 token |
| G10 | 准入的"两大表"（知识图谱节点表、公差表）未定稿 | 图谱与公差模块无法并行 | 先产出两张 CSV/JSON，作为全项目共享事实源 |

## 九、验收标准建议（把策划案的模糊描述变成可测项）

| 模块 | 可测指标 |
|---|---|
| 国标 RAG 溯源 | 课内探针召回率 ≥ 95%；课外探针拒答率 ≥ 95%；每条回答 100% 带出处（文档 + 页码/条款号） |
| 知识边界门控 | 课内/课外覆盖率分布存在安全间隔带（对标作品：0.654 vs 0.361，τ=0.50） |
| 公差侦探 | 对 GB/T 1800 标准查询 100% 与标准表一致（用 20 组固定样例回归） |
| 3D 三视图联动 | 20 个标准模型的三视图与教材标准答案一致；交互帧率 ≥ 30fps |
| 剖切沙盒 | 全剖/半剖/局部剖各 3 例，剖面线方向与间距符合 GB/T 4457.5 |
| 虚拟画图教练 | 8 类圆弧连接（外切/内切/混合）步骤正确率 100%（几何解析可证） |
| 智能找茬 | 在 50 张标注样本上手绘错误检出率与误报率（需先定错误码表） |
| 知识图谱 | 节点 ≥ 70、关系 ≥ 100，含前置依赖与对比边；答错能触发前置推送 |

## 十、结论（给决策用）

1. **对标作品的方案书已经把"怎么做"写到了可复刻的颗粒度**（父子切分、混合检索权重、IDF 门控阈值、七类事件流、契约式模块），架构不必重新发明，**照搬骨架、换课程域**是最优路径。
2. **机械制图比材料实验"更硬"的地方有两个**：一是 3D/2D 联动（需要真几何内核），二是手绘批改（需要真 CV）。这两块是项目的"技术看点"，也是"翻车点"。
3. **最值得先做的三个模块**（投入产出比）：公差与配合侦探（纯规则，零幻觉，好演示）→ 虚拟画图教练（纯 2D 动画，效果直观）→ 国标 RAG 溯源（骨架必备）。
