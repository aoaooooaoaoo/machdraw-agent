# 08 · 确定性计算引擎说明

> 项目原则：**凡是能算的，绝不让大模型背。**
> 本文件说明三个"零幻觉"计算引擎的标准依据、公式、数据来源、锚点校验与已知限制。
>
> 引擎文件（纯 Python 标准库，不依赖网络 / 大模型 / 第三方包）：
>
> - `apps/api/app/domain/tolerance.py` —— 极限与配合（GB/T 1800.1-2020 / 1800.2-2020）
> - `apps/api/app/geometry/arc.py` —— 圆弧连接（平面图形作图）
> - `apps/api/app/domain/thread.py` —— 螺纹与标准件比例画法（GB/T 4459.1 / 5782 / 7307 / 5796）
>
> 测试：
>
> - `apps/api/tests/test_tolerance.py`（28 项）
> - `apps/api/tests/test_arc.py`（11 项）
> - `apps/api/tests/test_thread.py`（16 项）
>
> 全部测试均可用 `D:\python\python.exe <测试文件>` 直接运行（也兼容 pytest）。

## 0. 共同设计约束

| 约束 | 实现方式 |
| --- | --- |
| 纯数据进出 | 输入只是字符串/数值，输出只是 `dict`/`list`，可直接 JSON 序列化给前端 |
| 不联网、不调 LLM | 模块内只 import `math`、`re`、`unicodedata`、`typing` |
| 不 import 契约层 | 三个模块都不依赖 `app/contracts/models.py`，可单独测试、单独部署 |
| 不静默出错 | 所有无法计算的组合显式抛 `ValueError`，异常信息为中文并说明原因与替代方案 |
| 数值可复现 | 所有数值是标准表值或标准公式，无随机、无时间依赖 |
| 尺寸分段语义 | 统一为 ISO 的 “over a, up to and including b”：**上限包含、下限不包含**（30 属于 (18, 30]，50 属于 (30, 50]） |

> 数值单位约定：`tolerance.py` 对外一律用 **mm**；内部计算用 **µm**，最后除以 1000 并保留 6 位小数。
> `arc.py` 长度为无量纲（与图纸单位一致），角度为**度**，数值保留 6 位小数。

### 1.2 标准公差 IT

标准公差因子（µm，D 为尺寸分段的几何平均值，mm）：

```text
i = 0.45 · D^(1/3) + 0.001 · D
```

各等级系数：IT5 = 7i，IT6 = 10i，IT7 = 16i，IT8 = 25i，IT9 = 40i，IT10 = 64i，IT11 = 100i。

工程实现上采用 **公式 + 表格混合**：`_IT_TABLE` 内嵌 GB/T 1800.1-2020 表 1 的逐档数值（µm），
公式用于教学解释和自检。之所以以表为准，是因为标准表在若干档位对公式结果作了取整
（例如 `>80~120` 段 `n` 的公式值 23.76 µm，标准表取 23 µm），表值才是“标准答案”。

尺寸分段（13 段，µm→mm 除以 1000）：

### 1.3 基本偏差

基本偏差是“靠近零线”的那个极限偏差：轴 a~h 取上偏差 `es`，轴 j~zc 取下偏差 `ei`；
孔 A~H 取下偏差 `EI`，孔 J~ZC 取上偏差 `ES`。

实现要点：

1. **轴 d/e/f/g**：按中间尺寸段查 `es`（GB/T 1800.2 表 4）。
2. **轴 h**：`es = 0`。
3. **轴 js**：`es = +IT/2，ei = −IT/2`（IT 为奇数时出现 0.5 µm，如 `js7` 在 >18~30 为 ±10.5 µm）。
4. **轴 j**：按主尺寸段查 `ei`（GB/T 1800.2 表 4），仅 IT5~IT8 为标准；j8 仅 ≤3 mm 有标准值。
5. **轴 k**：`ei = +0.6·D^(1/3)`（取整，IT5~IT7）；`ei = 0`（IT8 及更粗、以及 ≤3 mm）。
   表值：≤3:0，3~6:1，6~10:1，10~18:1，18~30:2，30~50:2，50~80:2，80~120:3，
   120~180:3，180~250:4，250~315:4，315~400:4，400~500:5（µm）。
6. **轴 m**：`ei = IT7 − IT6`，但 ≤3 mm 标准表取 **2 µm**（公式值 4 µm，以表为准）。
7. **轴 n**：`ei = +5·D^0.34`；表值（µm）：≤3:4，3~6:8，6~10:10，10~18:12，18~30:15，
   30~50:17，50~80:20，80~120:23，120~180:27，180~250:31，250~315:34，315~400:37，400~500:40。
8. **轴 p/r/s**：取标准表 `ei`。p 按主尺寸段；r、s 因标准按中间尺寸段细分，逐段内嵌（µm）。
9. **孔 H**：`EI = 0，ES = +IT`。
10. **孔 JS**：`ES = +IT/2，EI = −IT/2`。
11. **孔 J**：查表（GB/T 1800.2 表 2/表 8），仅 IT6~IT8 为标准。
12. **孔 K、M、N**（等级 ≤IT8）：

    ```text
    ES = −ei(同名轴) + Δ,   Δ = IT_n − IT_(n−1)
    ```

    K 中的 `ei` 取 `+0.6·D^(1/3)`（与轴 k 的基本偏差定义一致，与 k 等级无关）；
    等级 >IT8 时：M 取 `ES = −ei`，N 按 GB/T 1800.1 表 3 取 `ES = 0`（尺寸 >3~500 mm），
    K 的 K9~K11 在 ≤500 mm 内不是标准公差带，抛 `ValueError`。
13. **孔 P、R、S**：

    ```text
    grade ≤ IT7:  ES = −ei(同名轴) + Δ
    grade > IT7:  ES = −ei
    ```

14. **Δ 表**（GB/T 1800.2 表 3，µm，依次对应 IT3~IT8）：

### 1.4 配合计算（`solve_fit`）

```text
极限尺寸：孔 max = D + ES，孔 min = D + EI；轴 max = D + es，轴 min = D + ei
最大间隙 Xmax = ES − ei
最小间隙 Xmin = EI − es        （负值即过盈）
最大过盈 Ymax = es − EI
配合类型：Xmax > 0 且 Xmin ≥ 0 → 间隙配合
          Xmax ≤ 0            → 过盈配合
          否则                 → 过渡配合
配合制：  孔代号为 H → 基孔制；轴代号为 h → 基轴制；否则 → 非基准制
```

`fit.note` 与 `process_hint` 由确定性规则拼装（按配合类型 + 公差等级选择加工方式与 Ra 建议），
不含随机文案、不含 LLM 生成。

返回字段严格按需求约定：
`basic_size / system / hole{code,IT,ES,EI,max,min} / shaft{code,IT,es,ei,max,min} /
fit{type,max_gap,min_gap,max_interference,note} / tolerance_zone{hole,shaft} /
process_hint / refs`。

> **与任务描述示例的一个数值差异（已核对标准）**
> 任务示例中 `Φ30 H7/k6` 给出 `min_gap = -0.013`、`max_interference = 0.013`。
> 按 GB/T 1800 的极限尺寸定义：`Xmin = EI − es = 0 − 0.015 = −0.015 mm`，
> 故 `max_interference = es − EI = 0.015 mm`（0.013 恰为 IT6 的值，疑为示例笔误）。
> 引擎按标准公式输出 `min_gap = -0.015`、`max_interference = 0.015`，
> 其余示例数值（`max_gap = 0.019` 等）与标准一致。

### 1.6 `parse_fit` 支持格式

```text
"Φ30 H7/k6"  "Ø30H7/k6"  "30 H7 k6"  "Φ50H7"  "Φ30h6"  "Φ20 H8/f7"  "φ45 js6"
```

- 直径符号 `Φ φ Ø ø ⌀ ∅` 与全角字符会先做归一化；
- 大写字母 = 孔，小写字母 = 轴；只写一个代号时，另一侧字段为 `None`；
- 返回固定 7 个字段：`phi / hole / shaft / hole_letter / hole_grade / shaft_letter / shaft_grade`。

### 1.7 已知限制（显式抛 `ValueError`）

1. **尺寸**：仅 (0, 500] mm；>500 mm 抛 `ValueError`。
2. **等级**：仅 IT5~IT11；IT01~IT4、IT12~IT18 抛 `ValueError`。
3. **代号**：仅内嵌轴 `d,e,f,g,h,js,j,k,m,n,p,r,s` 与孔 `H,JS,J,K,M,N,P,R,S`；
   其它代号（如 t、u、x、zc、A、G 等）抛 `ValueError`。
4. **非标准公差带**：
   - 孔 K9~K11（≤500 mm 无此标准带）→ `ValueError`；
   - 孔 J5、J9~J11 → `ValueError`（J 仅 IT6~IT8）；
   - 轴 j9~j11 → `ValueError`（j 仅 IT5~IT7）；轴 j8 仅 ≤3 mm。
5. **N9~N11 的特殊性**：GB/T 1800.1 表 3 规定尺寸 >3~500 mm 时孔 N（等级 >IT8）
   的 `ES = 0`（即与 H 同位），本引擎按标准表实现；≤3 mm 时 `ES = −ei(n)`。
6. **≤3 mm 的 m、n**：标准表特殊值（m=2 µm、n=4 µm）与公式值（4 µm、6.06 µm）不同，
   已按表值实现。
7. **IT 表格与公式的取整差异**：个别尺寸段的公式推导值与标准表取整值不同（如 n@80~120），
   一律以标准表为准。

## 2. 引擎二：圆弧连接 `arc.py`

### 2.1 标准依据与教学目标

依据 GB/T 4458.4-2003 与教材“平面图形画法”中圆弧连接的作图方法，覆盖 8 类经典连接中的 4 类：

| 类型 | `build_steps` 的 `kind` | 几何条件 |
| --- | --- | --- |
| 直线—直线（圆角） | `line_line` | 圆心距两直线均为 r |
| 直线—圆弧 | `line_arc` | 圆心距直线 r，距已知圆圆心 R±r |
| 圆弧—圆弧外切 | `arc_arc_outer` | 两个圆心距分别为 r1+r、r2+r |
| 圆弧—圆弧内切 | `arc_arc_inner` | 两个圆心距分别为 \|r1−r\|、\|r2−r\| |

### 2.2 公式与推导

1. **圆与直线相切**：圆心到直线距离 = r；切点 = 圆心到直线的垂足。
2. **两直线圆角**：设两直线单位方向 `u1, u2`，交点为 V，夹角 θ：

   ```text
   圆心 = V + (u1 ± u2) · r / sin θ        （4 个候选，取两垂足都落在给定射线上的一个）
   切点 = 圆心在两条直线上的垂足
   ```

   该式来自：圆心在角平分线上、到直线距离为 r，故距 V 为 `r/sin(θ/2)`；
   而 `|u1 ± u2|·r/sinθ` 恰好给出角平分线方向上的该距离。

3. **直线—点 / 直线—圆**：以直线—点为例，令 A′ 为距直线 r 的平行线起点、u 为直线方向，
   设圆心 C = A′ + t·u，`w = A′ − P`，由 `|C − P| = r` 得

   ```text
   t² + 2(w·u)t + |w|² − r² = 0
   ```

   判别式 < 0 即无解（抛 `ValueError`）。

4. **两圆交点**（圆—圆连接求圆心）：标准两圆交点公式

   ```text
   d = |O2 − O1|,  a = (R1² − R2² + d²) / (2d),  h = sqrt(R1² − a²)
   C = O1 + u·a ± n·h        （u 为 O1→O2 单位向量，n 为 u 的左法向）
   切点 T1 = O1 + (C−O1)/|C−O1| · r1，T2 同理
   ```

### 2.3 返回结构与绘图指令

- 坐标一律 `tuple[float, float]`，保留 6 位小数。
- `draw` / `svg_paths` 为绘图指令列表：
  - 直线 `{"op":"line","a":[x,y],"b":[x,y]}`
  - 圆弧 `{"op":"arc","c":[x,y],"r":R,"start_angle":a,"end_angle":b}`（度，逆时针，保证劣弧）
  - 点 `{"op":"point","p":[x,y],"label":"O"}`
  - 已知圆（辅助）`{"op":"circle","c":[x,y],"r":R,"label":"O1"}`（前端可忽略或按整圆绘制）
- `build_steps` 返回 `{"kind","steps":[{n,title,detail,draw}],"svg_paths","summary","result"}`，
  其中 `result` 保留全部数值（圆心、切点、圆弧指令、solutions 等），供前端联动高亮。
- 每个函数都在 `formula` 字段给出**求圆心的几何依据**（教学讲解用）。

| 用例 | 期望 | 实测 | 结果 |
| --- | --- | --- | :---: |
| R10 圆角连接 x/y 正方向两条垂直直线 | 圆心 (10,10)，切点 (10,0)、(0,10) | (10.000000,10.000000)、(10.000000,0.000000)、(0.000000,10.000000) | ✅ |

### 2.5 已知限制

1. `build_steps` 只覆盖上述 4 类；另外 4 类（圆弧—直线反向、圆弧内切于直线等）未提供分步脚本，
   但底层函数可组合求解。
2. 圆弧 `arc` 指令固定取**劣弧**（圆心角 ≤180°）；若教学需要优弧，需前端按 `result` 自行处理。
3. `connect_arc_to_arc` 一次给出最多 2 组解，`build_steps` 取第一组（`solutions[0]`），
   其余解保留在 `result.solutions` 中供选择。
4. 两直线平行/重合、两圆相离或包含、半径无法满足相切条件时，抛 `ValueError`（中文原因）。

## 3. 引擎三：螺纹与标准件 `thread.py`

### 3.1 标准依据

| 内容 | 依据 |
| --- | --- |
| 普通螺纹基本牙型 / 直径与螺距系列 | GB/T 192-2003、GB/T 193-2003 |
| 普通螺纹基本尺寸 / 公差 | GB/T 196-2003、GB/T 197-2018 |
| 梯形螺纹 | GB/T 5796.1~5796.4-2005 |
| 55° 非密封管螺纹 | GB/T 7307-2001 |
| 螺纹及螺纹紧固件表示法 | GB/T 4459.1-1995 |
| 六角头螺栓 | GB/T 5782-2016 |

### 3.2 数据来源

- **粗牙螺距**：GB/T 193-2003 常用规格 40 档（M1~M64），内嵌于 `COARSE_PITCH`；
  例如 M10→1.5、M12→1.75、M20→2.5、M24→3.0。
- **管螺纹**：GB/T 7307-2001 常用尺寸代号 15 档（G1/8~G4），内嵌 `PIPE_THREADS`，
  给出大径 d 与螺距 P；例如 G1/2：d=20.955、P=1.814（**不是** 0.5×25.4=12.7）。
- **梯形螺纹**：`Tr24×5` 等由标记直接给出 d、P，按基本尺寸公式计算 d2、d1。

### 3.3 比例画法规则

普通螺纹（GB/T 4459.1 规定画法 + 教材比例画法）：

```text
d1 = d2 = 0.85d        （制图简化值，不是螺纹真实小径/中径）
大径粗实线、小径细实线；小径细实线画入倒角内
端视图中小径细实线圆只画约 3/4 圈，不画倒角圆
螺纹终止线粗实线；剖面线画到粗实线为止
```

梯形螺纹（基本尺寸近似）：

```text
d2 = d − 0.5P
d1 = d − P
```

55° 管螺纹（牙型关系）：

```text
d2 = d − 0.640327P
d1 = d − 1.280654P
```

六角头螺栓 GB/T 5782 比例画法：

```text
头部高度 k ≈ 0.7d
头部对角 e ≈ 2d
对边宽度 s = e·cos30° ≈ 1.732d
头部简化圆弧 r ≈ 1.5d
螺纹长度 b：l ≤ 125 → 2d+6；125 < l ≤ 200 → 2d+12；l > 200 → 2d+25
垫圈 d_w ≈ 2.2d、厚 ≈ 0.15d；螺母高 ≈ 0.8d
```

> `bolt_drawing("M10")` 未给出长度时取示例长度 l = 4d（并在 `table.length_explicit=False` 注明），
> 以避免“没有长度就编一个标准长度”的伪精确。

### 3.5 已知限制

1. 螺纹标记解析覆盖 M（普通螺纹，含细牙/公差带/LH/旋合长度）、Tr（梯形）、G（55° 非密封管螺纹）；
   未覆盖 Rp/Rc（密封管螺纹）、NPT、BSPT、锯齿形螺纹等。
2. 粗牙螺距仅内嵌常用 40 档；非首选直径（如 M7.5、M15）抛 `ValueError`。
3. 管螺纹仅内嵌常用 15 档尺寸代号；其它代号抛 `ValueError`。
4. `thread_drawing` 的 `d1/d2` 是**制图比例值**，不是螺纹真实中径/小径；
   需要真实基本尺寸时应查 GB/T 196 / GB/T 7307 表，引擎已在 `table.draw_ratio` 中显式注明口径。
5. 螺栓比例画法只覆盖六角头螺栓（GB/T 5782），未覆盖双头螺柱、螺钉、螺母、垫圈的完整绘图；
   但 `table` 中给出了垫圈、螺母的比例参考值。

### 4.3 数据核对记录

为保证“数据准确性是硬要求”，开发时对以下来源逐值核对：

1. GB/T 1800.1-2020（ISO 286-1:2010）表 1：IT5~IT11 共 13×7=91 个公差值；
2. 同标准表 2~表 5：孔 A~M、孔 N~ZC、轴 a~j、轴 k~zc 的基本偏差；

## 5. 与其它模块的接口约定
