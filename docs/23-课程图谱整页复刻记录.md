### 2.1 `CanvasFeature.page`


`features/graph/index.ts`：

### 2.2 `App.tsx`

```tsx
const PageComponent = getCanvasFeature(activeFeature)?.page;
const latestArtifact = session.artifacts[session.artifacts.length - 1] ?? EMPTY_ARTIFACT;

<div className="workbench">
  <LeftNav />
  {PageComponent ? (
    <div style={{ gridColumn: '2 / -1', minWidth: 0, minHeight: 0, display: 'flex', overflow: 'hidden' }}>
      <PageComponent
        artifact={latestArtifact}
        onAsk={setDraft}
        messages={session.messages}
        busy={session.streaming}
        onSendMessage={(text) => { void send(text); }}
      />
    </div>
  ) : (
    <>
      <ChatPanel />
      <CanvasPanel />
    </>
  )}
</div>
```

- `EMPTY_ARTIFACT` 是模块级常量（`receivedAt: 0`），避免每次渲染给页面新对象导致状态重置；
- 整页模式下 `send()` 仍写到当前 graph 会话，Artifact 到达后 `App` 把 latestArtifact 传给页面，页面 `[artifact.receivedAt]` 切 tab/聚焦；
- 其它模块的 `getCanvasFeature(id)?.page` 为 undefined，仍走三栏。

## 3. 知识图谱页实现要点

### 3.1 复用并扩展 `Overview`

`modules/graph/Overview.tsx` 增加可选 props（画布模式不传，行为不变）：

```ts
externalSelectedId?: string | null;   // 页面控制选中
onSelect?: (id: string | null) => void;
hiddenLevels?: Set<string>;           // tier
hiddenSectors?: Set<number>;          // galaxy index
denseLabels?: boolean;                // 多显示 core/branch/concept 标签
fillHeight?: boolean;                 // SVG 撑满整页高度
```

- 点击节点：`onSelect` 存在时切换选中/取消；再点同一节点或点空白 → `resetView()`（回 100% 全景）；
- `centerOn` / 搜索命中同步 `onSelect`，详情面板跟随；
- 隐藏节点/边/星系环；`visibleIds` 过滤边；
- `fillHeight` 时 SVG `width/height:100%` + `preserveAspectRatio="xMidYMid meet"`，星图适配整页；
- 画布模式仍走原来的 `onFocus`（进焦点关系），行为不变。

### 3.2 详情面板

`GraphPage` 根据选中节点从 `/api/graph` 计算：

- label / `kp_id` / level（`node.level` 优先，旧数据按 tier 推导）/ tier / 章 / 掌握状态；
- `desc`、`points`（要点列表）、`commonMistakes`（黄色易错块）、`refs`（课程出处）、`section`；
- **前置知识**：`edges` 里 `rel === 'prereq'` 且 `target === node.id` → 可点击换节点；
- **后继知识**：`source === node.id` → 可点击；
- **关联课程问题**：`q.node_ids.includes(node.id)` → 点击 `jumpToQuestion(qid)`；
- 面包屑：优先 `node.parent`，旧数据用 `compose` 边推父链（加环保护，最多 6 层）；
- 点空白/再点节点 → 面板消失并回全景（实测）。

### 3.3 筛选与图例

- 层级 L1-L4：`LEVEL_TIERS = {1:core, 2:trackA+trackB, 3:branch, 4:concept}`；点击隐藏/恢复；
- 章：`full.sectors`（9 个）或 `full.chapters` 兜底；点击隐藏对应 galaxy；
- 图例：层级 4 类（`TIER_COLOR`）+ 关系 4 类（`REL_STYLE`，contrast/compose 虚线）。

## 4. 问题图谱页实现要点

### 4.1 三列与数据

`QuestionPage` 从 `full.question_layers` 取三列（11 / 8 / 7），每列头：`L{layer} {name}` + 数量 + `desc` + 2px 色条。
卡片：`T{layer}-{index}`、bloom 标签（配色）、题干 3 行截断可展开、知识点 chips、hint 折叠。

### 4.2 DOM 锚点测量

```ts
const measure = () => {
  const board = boardRef.current;
  if (!board) return;
  const base = board.getBoundingClientRect();
  const next: Record<string, Anchors> = {};
  for (const [qid, el] of cardRefs.current) {
    const r = el.getBoundingClientRect();
    next[qid] = {
      left: { x: r.left - base.left, y: r.top - base.top + r.height / 2 },
      right: { x: r.right - base.left, y: r.top - base.top + r.height / 2 },
    };
  }
  setAnchors(next);
};

useLayoutEffect(() => {
  measure();
  const t = window.setTimeout(measure, 120);      // 字体/布局稳定后再量
  const ro = new ResizeObserver(measure);
  if (boardRef.current) ro.observe(boardRef.current);
  window.addEventListener('resize', measure);
  return () => { window.clearTimeout(t); ro.disconnect(); window.removeEventListener('resize', measure); };
}, []);

useEffect(() => {
  const t = window.setTimeout(measure, 40);        // 展开题干/提示后高度变化重测
  return () => window.clearTimeout(t);
}, [expanded, hintOpen, full]);
```

### 4.3 贝塞尔连线（同源扇形散开）

```ts
const groups = new Map<string, typeof edges>();
for (const e of edges) (groups.get(e.source) ?? groups.set(e.source, []).get(e.source)!).push(e);
// 或等价：按 source 分组
for (const [source, list] of groups) {
  const sorted = [...list].sort(
    (a, b) => (anchors[a.target]?.left.y ?? 0) - (anchors[b.target]?.left.y ?? 0),
  );
  sorted.forEach((e, i) => {
    const a = anchors[source];
    const b = anchors[e.target];
    const off = (i - (sorted.length - 1) / 2) * 10;
    const x1 = a.right.x, y1 = a.right.y + off;
    const x2 = b.left.x,   y2 = b.left.y + off * 0.4;
    const dx = Math.max(48, (x2 - x1) * 0.46);
    const d = `M ${x1} ${y1} C ${x1 + dx} ${y1}, ${x2 - dx} ${y2}, ${x2} ${y2}`;
    // on = 路径上的边；dim = 其余
  });
}
```

渲染：SVG 绝对定位在 board 上（`pointer-events:none`），`prereq` 青色实线、`cause` 琥珀、`contrast` 紫色虚线（`stroke-dasharray:6 5`），每类一个箭头 marker；
高亮边叠一条 `qp-flow` 流动虚线（`stroke-dashoffset` 动画）。

### 4.4 上下游路径高亮

```ts
const activeQid = hover ?? selected ?? 'Q-004';   // 默认展示最长链起点
```

### 4.5 详情抽屉

## 5. 双视图互跳链路

```
知识图谱详情「关联课程问题」 ──jumpToQuestion(qid)──► setTab('question') + setQFocus(qid)
问题图谱卡片知识点 chip ──jumpToKnowledge(kid)──────► setTab('knowledge') + setSelectedId(kid)
chat graph artifact {mode,focus} ──Page effect──────► 切对应 tab + 聚焦
```

`GraphPage` 的 `artifact.receivedAt` effect：

```ts
const mode = data.mode === 'question' ? 'question' : 'knowledge';
setTab(mode);
if (mode === 'question') setQFocus(data.focus.id);
else setSelectedId(data.focus.id);
```

当前 `kg_lookup` artifact 只有 `focus` 时按 knowledge 处理；后端后续补 `mode` 即可切问题页。

## 6. Agent 抽屉

- 入口：页面右上「Agent 问答」按钮（`gp-agent-btn`）；
- 抽屉：复用 `MessageItem`（工具卡/思考/流式正文/错误块）+ 输入框；

## 8. 没复刻到位的地方（如实列出）

1. **不是真 3D 星图**：按约束用 SVG 2D（后端无 3D 坐标，我们也禁 three/R3F）。参考作品是 R3F 真三维六芒；我们复刻的是「中心 + 9 章星系 + 径向/螺旋布局」的 2D 投影，缩放/平移/标签/详情齐全，但没有 3D 环绕。后端 `sectors[].angle` 已接入布局（星系按章序分布），`tilt` 未用。
2. **标签不是 169 个全开**：整页 `denseLabels` 只开 core/branch/concept（约 30 个），其余放大到 ≥220% 才出现；避免整页糊成一片。参考作品的标签策略是「按相机距离分级」，我们是按 tier + zoom。
3. **`contrast` 只做了虚线，不是双箭头**：后端 3 条同层对比边用紫色虚线 + 单箭头区分；未做双向箭头（避免与有向 path 高亮语义冲突）。
4. **问题图谱的默认高亮路径**：默认 `Q-004` 起（后端给的最长链），但没有在页面初始化时主动把 `Q-004` 设为 `selected`（否则一进来抽屉就开）；是高亮而非选中。若后端链首变化，需把 `DEFAULT_HIGHLIGHT` 改为配置。
5. **面包屑不完整**：后端只有 12 个节点有 `parent`，其余用 `compose` 边推父链；很多节点会只有「章 → 当前节点」，不是完整五级路径。
6. **graph 画布模式没有独立入口**：整页替换了 graph 模块的左栏入口；graph 的右栏画布模式仍注册，但只能从全局对话的 graph artifact 进入。如果你希望「同模块可切回画布」，需要在页面加一个「画布模式」按钮并把 activeFeature/会话切到一个非 page 入口（本次验收只要求其它模块画布可用，已测）。
7. **问题详情 `answer` 目前后端未下发**：抽屉有 `answer` 就渲染，没有则只显示 hint/blindSpot；不伪造答案。
8. **问题/知识双视图的 artifact 契约仍以 `focus` 为主**：我们兼容了 `{mode,focus}`，但当前 kg_lookup 只带 focus；等后端补 mode 后问题页的 artifact 入口才完整。
9. **页面没有 URL 路由**：整页/问题 tab 都是组件状态，刷新会回知识图谱默认；参考作品也没有路由。
10. **本页没有做「层级/章筛选的 URL 记忆」和移动端专属布局**；窄屏复用桌面三列（横向滚动）。
