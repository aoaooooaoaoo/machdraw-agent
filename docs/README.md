## 四句话结论

1. **参考包里的"源码"并不存在**——那是参赛交付包（项目书 + 演示视频 + 知识库），但项目书把架构写到了可复刻的颗粒度，骨架可以直接照抄。
2. **线上站点补齐了最后一块**：项目书只说"10 项教学工具"，线上 `/api/health` 直接列出了这 10 个名字；SSE 事件协议、chunk/artifact 数据结构也都抓到了——**不需要源码就能对齐实现**（见 05 文档）。
3. **机械制图比参考课程"更硬"两处**：三视图/剖切需要真几何内核（不是 three.js 画球棍），手绘批改需要真 CV（参考作品完全没有）。
4. **先做能算准的（公差 / 圆弧作图 / 三视图），再做能问对的（RAG + 门控），最后做能判错的（视觉找茬）**——这个顺序反了会翻车。
