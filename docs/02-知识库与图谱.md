## 2. 数据契约

> 以下字段表与 SPEC 第 3 节逐字一致；示例取自真实落盘数据（长字段截断）。所有文件为 **UTF-8、一行一 JSON、无 BOM**。

### 2.1 `kb/knowledge/kp.jsonl`（一行一个知识点）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `kp_id` | str | ✓ | `KP-<CODE>-<三位>`，CODE∈{INTRO,NUCPHY,NEUTRON,DIFF,SPEC,BURN,REACT,KIN,FUEL,DESIGN} |
| `chapter` | str | ✓ | 完整章名，逐字匹配 SPEC 第 1 节（如 `"第四章 中子扩散理论与计算"`） |
| `section` | str | ✓ | 小节路径 `"章.节 标题"`，如 `"4.2 增殖介质单能中子扩散方程"` |
| `term` | str | ✓ | 知识点名称 |
| `aliases` | str[] | ✓ | 别名/学生常说错的说法（各 KP 统一 3 个，用于检索与图库对齐） |
| `definition` | str | ✓ | 教材口径的定义，**自写表述**（80~200 字） |
| `points` | str[] | ✓ | 3~5 条可考细节（公式、条件、量纲、数值） |
| `common_mistakes` | str[] | ✓ | 2~4 条常见错误（学生视角） |
| `refs` | str[] | ✓ | 依据：`教材 第X章 X.Y 节 p.N` / `课件 第X章 第N页` / `复习笔记 p.N` |
| `bloom` | str | ✓ | 记忆/理解/应用/分析/综合 |
| `level` | int | ✓ | 1~4（难度） |

### 2.2 `kb/graph/nodes.jsonl`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | str | `KN-<三位>`，全库唯一、建议连续 |

| `label` | str | 图上显示名（一般取 KP 的 term） |
| `tier` | str | `core` / `trackA` / `trackB` / `branch` / `concept` |
| `chapter` | str | 完整章名，逐字匹配 SPEC |
| `state` | str | 固定 `"未学"` |

```json
{"id": "KN-001", "kp_id": "KP-INTRO-001", "label": "核反应堆",
 "tier": "branch", "chapter": "第一章 绪论", "state": "未学"}
```

### 2.3 `kb/graph/edges.jsonl`

| 字段 | 类型 | 说明 |
|---|---|---|
| `source` | str | 起点节点 id（必须存在） |
| `target` | str | 终点节点 id（必须存在） |
| `rel` | str | `prereq` / `contrast` / `cause` / `compose` |
| `note` | str | 一句话说清"为什么有这条边"（校验强制非空） |

```json
{"source": "KN-001", "target": "KN-002", "rel": "prereq",
 "note": "先明确核反应堆是可控自持链式（或聚变）反应的装置，才能按机理、能谱、冷却剂分类。"}
```

约束：无自环、无重复 `(source,target,rel)`、无孤立节点（度 ≥1）；`contrast` 只存一条，`prereq/cause/compose` 有方向（见 4.5）。

## 3. 内容质量方法

### 3.1 写作规范（每条 KP 的"四件套"）

| 维度 | 规则 | 全库实测 |
|---|---|---|
| `definition` | 用**自己的话**写，覆盖定义的要素（是什么、由什么决定、与相邻概念的区别），不抄教材原句 | 175 条，均 **149 字**（106~200 字，全部落在 80~200 区间） |
| `points` | 必须是**可考的细节**：公式、条件、量纲、数值、判据；不写"很重要""要掌握"这类空话 | 共 **707 条**，均 4.0 条/KP（3~5 条） |
| `common_mistakes` | 用**学生视角**写真错：写"学生会怎么错、错成什么数"，不写"注意 XX" | 共 **351 条**，2~4 条/KP |
| `refs` | 每条至少 1 条教材依据，能翻到具体节与页；课件/笔记作交叉印证 | 共 **397 条**，均 2.3 条/KP；175/175 有教材依据 |

### 3.2 refs 的格式与页码口径（可复核）

所有 refs 命中三类白名单格式，正则校验 397/397 通过：

| 前缀 | 格式 | 页码口径 | 实测范围 |
|---|---|---|---|
| `教材` | `教材 第X章 X.Y 节 p.N` | **吴宏春 DOC（`working/extract/doc/核反应堆物理-修改版（20140116曹）.txt`）目录页次**——目录每节后的数字即书内页码 | p.5 ~ p.176 |
| `课件` | `课件 第X章 第N页` | `working/extract/pptx/第N章 *.slides.md` 中的 `## Slide N` | 各 deck 内（ch1≤15、ch2≤36、ch3≤59、ch4≤51、ch5≤23、ch6≤38、ch7≤35、ch8≤37、ch9≤46、ch10≤25） |
| `复习笔记` | `复习笔记 p.N` | 笔记印刷页码（页眉数字） | p.3 ~ p.27 |

**为什么不用 PDF 清样的页码**：`核反应堆物理分析(内文)清样 (1).pdf` 255 页的文字层是坏的（内嵌字体无 ToUnicode，全部 255 页仅能读出 29 个汉字，其余为乱码），无法定位"某节在第几页"。因此教材侧统一改用**同一课程教材的 Word 版抽取文本 + 目录页次**，既逐字可核，又与印刷页对应。此口径已写入 5.2 复核清单。

### 3.3 典型"学生真错"的写法（示例）

| KP | 错误（示例） | 为什么这样写 |
|---|---|---|

### 3.4 校验器 `kb/graph/_check.py`（正向 + 反向）

正向校验（真实数据）：**0 错误**、退出码 0。覆盖：
1. 逐行 JSON 合法（含 BOM 容错 `utf-8-sig`）、无空行；
2. 字段齐全、类型正确、取值域合法（chapter 逐字匹配 SPEC；tier/rel/layer/bloom/level 白名单）；
3. ID 唯一且符合规约（`KP-<CODE>-<3位>` / `KN-<3位>` / `Q-<3位>`）；
4. `nodes.kp_id` 回指存在、1 个 KP 至多 1 个节点、`state` 固定"未学"；
5. 边端点存在、无自环、无重复边、`note` 非空、无孤立节点；
6. `questions.kp_ids` 全部存在、layer∈{1,2,3}、题干/提示非空；
7. `_terms.tsv` 与 `kp.jsonl` 一一对应；
8. 输出逐章 kp 数、tier/rel/layer 分布、kp 覆盖率、错误/告警清单。

反向校验（注入错误）：人为注入 **14 处错误**（覆盖 13 类：章名不符、节点 ID 重复、边端点悬空、自环、rel 非法、note 空、重复边、孤立节点、qid 格式错、layer 越界、题干空、hint 空、kp_ids 悬空；其中孤立节点因重复 ID 被报两次），**14 处全部被捕获并以退出码 1 失败**，证明校验器不是"只打印不拦截"。

## 4. 图谱设计

### 4.1 `core` 只有 10 个：选"穴位"不选"大节点"

| 节点 | KP | 章 | 对应能力/引擎 |
|---|---|---|---|
| KN-017 宏观截面 | KP-NUCPHY-008 | 二 | 反应率链入口 → 群常数/临界计算 |
| KN-028 缓发中子 | KP-NUCPHY-019 | 二 | 动力学链入口 → `kinetics_calc` |
| KN-036 有效增殖系数 k_eff | KP-NEUTRON-002 | 三 | 临界链入口 → `critical_calc` |
| KN-039 反应性与反应性单位 | KP-NEUTRON-005 | 三 | 反应性刻度 → `reactivity_calc` |
| KN-045 四因子与六因子公式 | KP-NEUTRON-011 | 三 | 中子平衡脊柱（度 10，全图最高） |
| KN-070 单群临界方程 | KP-DIFF-010 | 四 | 临界计算核心 → `critical_calc` |
| KN-083 中子能谱 | KP-SPEC-001 | 五 | 能谱/群常数 → `spectrum_plot` |
| KN-111 氙中毒与功率水平 | KP-BURN-011 | 六 | 中毒链核心 → `poison_calc` |
| KN-118 反应性系数与温度系数 | KP-REACT-001 | 七 | 反馈链核心 → `reactivity_calc` |
| KN-140 点堆动力学方程 | KP-KIN-004 | 八 | 动力学核心 → `kinetics_calc` |

选取逻辑：**每个 `core` 必须是"一章的计算/推理枢纽"而非"内容最多的节点"**——它要么是确定性引擎（critical / kinetics / poison / reactivity / spectrum 等）某个公式的入口（k_eff、临界方程、点堆方程、氙平衡、温度系数），要么是三大硬能力之间的衔接点（四因子、反应性刻度、能谱）。10 个 core 全部落在第二~八章（教学主干）；第一章（绪论）、第九章（燃料管理）、第十章（核设计）以 `branch` 承载背景与工程出口，不占 core。

### 4.2 `trackA` / `trackB`：两条可并行的学习主线

| 主线 | 数量 | 章分布 | 覆盖什么 | 一句话 |
|---|---:|---|---|---|
| `trackA`（计算主线） | 43 | 三 18 / 四 14 / 五 5 / 九 3 / 十 3 | 截面→慢化→扩散→临界→功率→群常数→设计计算 | "会算"：从 ξ、Nc、斐克定律一路推到 k_eff 与功率峰因子 |
| `trackB`（工程主线） | 42 | 六 11 / 七 12 / 八 7 / 九 12 | 燃耗→中毒→控制→动力学→燃料管理 | "会控"：从氙碘链、温度系数一路推到换料与循环长度 |

两条主线之间并非互不相干：`trackA` 的"计算结果"是 `trackB` 的输入，图谱用 12 条 A↔B 跨线 `prereq` 把它们接起来，例如 `慢化时间、扩散时间与中子寿命`（三）→ `点堆模型与热中子寿期`（八）、`多群扩散方程与群常数`（四）→ `燃耗方程`（六）、`功率分布不均匀系数`（四）→ `功率系数与功率亏损`（七）、`热中子平均截面与 ga 修正`（五）→ `慢化剂温度系数`（七）。因此：**复习可按主线单独刷**（trackA 适合考前计算题，trackB 适合概念/工程题）；**答辩可按主线讲**（两条线恰好对应"临界与扩散计算"与"燃耗/控制/动力学"两大硬能力）。

### 4.3 `concept` 32 个：图谱负责"关系"，图库负责"看见"

`concept` 层收纳的是**易混概念**（如 弹性/非弹性散射、k∞/k_eff、p/f、几何/材料曲率、氙/钐、正/负阶跃、Out-In/低泄漏），共 32 个。两层皮的分工：

- 图谱侧：32 条 `contrast` 边把易混概念成对（其中 12 条两端均为 `concept`，其余是跨层对比——如 `单能中子扩散方程`(trackA) ↔ `能量相关中子扩散方程`(trackA)、`中子流密度`(concept) ↔ `中子通量密度`(branch)），`note` 写清"区别在哪、学生会怎么错"（示例：`微观截面 ↔ 宏观截面`——"σ 是单个核的反应概率度量，Σ=Nσ 是单位体积内所有核的合成量，学生常把二者单位混用"）。
- 图库侧：8 组 `pairs`（A/B 两栏 SVG + 差异点表 + 随堂题），把 `contrast` 边"可视化"，供 `comparison_pick` 工具与 `comparison` 画布直接使用。
- 一致性：`concept` 节点的 `kp_id` 与图库 `_link_terms.json` 的术语由 `link_figures.py` 对齐，保证"点开图能看到对应概念、点开概念能找到图"。

### 4.4 跨章 57 条（20.4%）：图谱不是 10 棵章内树

- 280 条边中 **57 条跨章**，占 20.4%；其中 `prereq` 48、`contrast` 6、`cause` 3。
- 典型跨章依赖（答辩可讲"知识是怎么串起来的"）：
  - `KN-005 反应堆内基本物理过程`（一）→ `KN-035 链式裂变反应与自持`（三）：绪论的"裂变—慢化—扩散—吸收"链条是第三章的起点；
  - `KN-007 分析目标与核心物理量`（一）→ `KN-036 k_eff`（三）：绪论列出的"两大物理量"之一正式定义在第三章；
  - `KN-006 输运方程`（一）→ `KN-075 输运方程与扩散近似 P1`（四）：第四章扩散方程的原方程；
  - `KN-028 缓发中子`（二）→ `KN-146 β_eff`（八）：有效缓发份额按中子价值加权；
  - `KN-030 共振现象`（二）→ `KN-088 有效共振积分`（五）：共振吸收是共振积分的物理来源。
- 设计意图：跨章边只连"真正存在前置依赖"的点（不硬凑），从而支持 `kg_lookup` 的"前置链/后继链"查询与 `graph` 画布的跨章高亮。

### 4.5 方向约定（写图/读图一致）

| rel | 方向 | 语义 | 例子 |
|---|---|---|---|
| `prereq` | source → target | **先学 source，才能学 target** | 单能扩散方程 → 材料曲率 |
| `cause` | 原因 → 结果 | 物理因果，不表示学习顺序 | 多普勒展宽 → 燃料温度系数（负） |
| `compose` | 整体 → 组成 | 父概念由子概念构成/包含 | 四因子公式 → ε / p / f / η |
| `contrast` | 对称（只存一条） | 两概念易混、需并置对比 | 几何曲率 ↔ 材料曲率 |

`note` 一律用一句话写"为什么有这条边"，禁止"相关""见上"之类空话（`_check.py` 强制非空，评审可抽读）。

### 4.6 叶子 23 个：是"知识链末端"，不是"漏连"

度为 1 的节点共 **23** 个，章分布：一 1 / 二 6 / 三 3 / 四 4 / 五 0 / 六 1 / 七 3 / 八 1 / 九 2 / 十 2。

| 类型 | 例子 | 为什么允许是叶子 |
|---|---|---|
| 工程专题/应用出口 | 先进堆型与第四代反应堆、高放废物嬗变与 ADS、换料堆芯安全评价 | 属于"背景/出口"知识，下游不再展开 |
| 算法/工艺终点 | 功率归一、源迭代法、临界计算的三类问题、少群截面拟合 | 计算链在此结束，无后继概念 |
| 事实型末端 | 平均自由程、核素原子核密度与富集度、包壳材料与厚度、燃料棒直径的选择 | 作为参数/事实被引用，自身不再派生 |

`_check.py` 只禁止**孤立节点（度 0）**，不禁止叶子（度 1）——因为把叶子硬接边会破坏语义。若答辩需要"更连通的图"，可按 5.3 的可选优化处理。
