数据是**由脚本生成**而非手写，因此可稳定复现、可增量维护：

```powershell
# 1) 重新生成知识点（会同时刷新 kp_index.json）
cd kb\knowledge\_src
D:\python\python.exe build_kp.py

# 2) 重新生成图谱与问题图谱（依赖 kp_index.json 做 key -> kp_id 映射）
cd ..\..\graph\_src
D:\python\python.exe build_graph.py
D:\python\python.exe build_questions.py

# 3) 自检（只读，不修改任何数据）
D:\python\python.exe selfcheck.py
```

**设计要点**：图谱节点与问题**不手写 `kp_id`**，而是用全局唯一的英文 `key`（如 `section_line`、`base_hole`）引用，由 `build_kp.py` 生成的 `kp_index.json` 映射成 `KP-XXX-NNN`。这样调整条目顺序、插入新条目时，图谱不会因为编号错位而引用到错误知识点。

**关于"按题量倾斜"的说明（如实交代偏差）**：

- 硬性下限已满足：第五章 32 条（≥30，为全书最多）、第三/四/七章 26/21/24 条（各 ≥20）、其余章各 ≥11 条（≥10）。

### 2.5 内容与术语规范

1. **原创改写**：所有 `definition`、`points`、`common_mistakes` 均为自撰；未从习题集/解答册/样题复制句子（题面仅在选题方向上有参考）。
2. **术语用现行规范名**：表面结构（旧称表面粗糙度，仅在 `aliases` 注明旧称）、极限与配合、几何公差（旧称形位公差，仅在 `aliases` 注明旧称）、上/下极限尺寸、上/下偏差、转向轮廓线（不写"转向线"）。不使用"光洁度""形位公差"等旧称作为条目主名。
3. **数值有依据**：幅面、线宽系列、Ra 数系、IT 等级、基本偏差代号、齿轮公式、螺纹标注格式等，均按国标或标准教材口径写；教材之间取值有差异的（比例画法系数、弹簧自由高度），在条目内明写"以所用教材为准"或标"近似式"。
4. **不确定就不编**：无法确认的数值不写死，改用"按 GB/T xxxx 表 1 选取"这类可核查表述，并进入 §6 复核清单。

## 3. 任务 B：知识图谱 `kb/graph/nodes.jsonl` + `edges.jsonl`

### 3.1 节点字段与 `tier` 口径

```json
{"id":"KN-001","kp_id":"KP-PROJ-004","label":"三视图形成","tier":"core","chapter":"第三章 点、直线和平面的投影","state":"未学"}
```

| 字段 | 说明 |
|---|---|
| `id` | 图内唯一编号 `KN-001`～`KN-169`，按 tier 分块连续编号 |
| `kp_id` | 指向 `kp.jsonl` 的知识点，**169 个节点对应 169 个不同知识点**（1:1） |
| `label` | 图谱显示名，短于 `term`，便于星图渲染（如 `尺寸基准（零件图）`、`剖视图`） |
| `tier` | 见下表；**落库用英文枚举值**，前端展示时映射中文标签 |
| `chapter` | 与所引用知识点一致 |
| `state` | 学情状态，默认 `未学`；Agent 侧可改为 `正在学`/`已掌握`/`需复习`（对应策划案灰/黄/绿/红） |

`tier` 取值与策划案"一核心、两主线、双分支"的映射：

| tier 值 | 中文展示 | 对应策划案结构 | 节点数 | 编号区间 |
|---|---|---|---:|---|
| `core` | 课程核心 | 一级（核心）"空间形体与工程表达"的四个支点 | 4 | KN-001～004 |

| `concept` | 关键概念 | 跨链的诊断锚点（截交线、相贯线、形体分析法、尺寸基准…） | 8 | KN-005～012 |

### 3.4 策划案点名的 6 组关键对比边（全部存在）

| 对比 | 节点对 | `note`（判别要点） |
|---|---|---|
| 截交线 ↔ 相贯线 | KN-005 ↔ KN-006 | 截交线由平面截切立体产生，相贯线由两立体表面相交产生 |
| 局部剖 ↔ 半剖 | KN-091 ↔ KN-090 | 半剖只能用于对称机件且以中心线分界，局部剖以波浪线分界、范围可大可小 |
| 视图 ↔ 剖视 | KN-085 ↔ KN-003 | 视图表达外形，剖视假想剖开后表达内部结构 |
| 尺寸基准 ↔ 工艺基准 | KN-154 ↔ KN-150 | 尺寸（设计）基准按设计要求定，工艺基准按加工测量要求定，二者可能不重合 |
