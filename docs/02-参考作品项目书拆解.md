## 二、六个模块的功能拆解（含可复用程度）

### 2.1 三栏工作台（前端外壳）
- 左栏：全局对话 + 6 个模块入口；中栏：对话流，**能看到"思考过程"、工具调用卡片、逐字流出**；右栏：随模块切换的可视化画布；顶部：账号与学习反馈入口。
- 配套能力：注册（学号/姓名首次输入自动建号、刷新不掉线）、学习评价报告、意见反馈、个人记录导出、**图片附件提问**。
- 复用度：★★★★★ 直接照抄信息架构。

### 2.2 全局对话
- 真实交互链路：提问 → 展开"思考过程" → 连续调用知识库检索工具（**每张工具卡片标明检索词与命中条数**）→ 回答逐字流出 → 结论下引用原文 → 右栏自动切到"证据溯源画布"，列出 N 段证据 + **匹配度百分比** + 出处标识，每张卡片可"展开完整段落/调阅解读/围绕此段追问"。
- 复用度：★★★★★

### 2.3 课程图谱（双模式，这是最值得抄的设计）
- **知识图谱模式**：3D 星图。中央"课程核心恒星"，外围 6 大知识星系，星系内展开"核心专题恒星 → 关键概念行星 → 实验方法层"**共五级 71 节点**，节点间 **4 类关系**（组成、因果、前置依赖、对比），**105 条关系**。鼠标拖拽 360° 环绕，点星球相机飞过去绕它旋转。
- **问题图谱模式**（★ 策划案缺这块）：13 道课程问题按"基础理解(6) → 实验表征(4) → 综合应用(3)"**三层递进**排布；每张卡挂**布鲁姆认知标签**（记忆/理解/分析/应用/创造）+ 关联知识点 chip；悬停高亮整条问题演进路径，点 chip 跳回知识图谱定位。
- 复用度：★★★★★ 数据结构（节点分级 + 4 类边 + 认知标签）直接照搬，只换内容。

### 2.4 知识库 RAG（核心，见第四节）
- 语料严格封闭在 15 份文献。
- 三个特征：(1) 结论后挂"作用—原文依据—面向后续哪一步"+ 出处编号（`chk_doc_…`）；(2) **主动交代边界**——"知识库未收录：…课程资料里都没有具体数据，我不代为补充"；(3) 右栏列出所有命中证据 + 所属文献 + 匹配度，可勾选讲义"锁定范围"再追问。
- 保留教师端完整版入口（上传、索引、后台管理）。
- 复用度：★★★★★

### 2.5 材料科学错题集（→ 我们的"智能找茬与错题本"）
- **六步诊改**：`原题 → 错误作答 → 根因 → 溯源 → 正解 → 避坑`
- 内置 **16 条**高频易错点，按 **12 个知识分类**归档。
- **根因归 6 类**：概念混淆、公式误用、模型理解偏差、忽略边界条件、计算失误、其他。
- "溯源"一栏**直接跳回教材/讲义对应段落**——错题不止被改正，还被接回原文。
- 三种入口：抽一道错题 / 贴自己的错题 / 按主题"从知识库出题"。
- 复用度：★★★★★（六步法 + 根因分类 可原样搬；但"视觉批改"是它没有的，我们要新增）

### 2.6 金相组织辨析（→ 我们的"剖视与投影辨析"）
- 21 张**外部补充**组织照片，按 3 类分类，支持按组织/材料名检索。
- 5 个页签：案例观察、组织对比、辨析练习、课程资料、资料问答。
- ★ **诚实标注机制**：页面明确写"实验四补充学习资料·**未审核**，不用于自动组织鉴定或定量测量"；教师审核前 Agent 不把它们当鉴定依据。
- 复用度：★★★★☆（页签结构与"未审核"标注机制值得抄——这是评审眼里的"学术诚实"加分点）

### 2.7 3D 可视化（→ 我们的 3D 模块，但难度差一个量级）
- 4 种晶胞球棍模型（SC/BCC/FCC/HCP），拖拽旋转缩放，可单独高亮八面体/四面体间隙或剖视晶胞。
- **原子半径滑杆**（教具式设计）：默认 r=0.269a，显示致密度 32.59%、状态"仍有空隙"；拖到相切点 t=1 时致密度回到教材值（FCC 74%/BCC 68%/SC 52%）；拖过头立即标红"原子重叠（物理上不允许）"。
- **关键工程决策**：`晶胞致密度、相切半径比等几何量全部由后端按晶体学公式算好下发，前端只负责渲染，避免两套口径打架。`
- 复用度：★★★☆☆（交互范式可抄；但**它的 3D 是"参数化刚体"，我们的三视图投影需要真几何内核，难度不在一个量级**）

### 2.8 费曼追问
- 学生复述概念 → Agent 做三件事：
  1. **逐句标注**：把学生原话拆开，按"讲对了(绿)/表述模糊(橙)/逻辑跳跃(红)"三色标在右栏画布，点标注看逐句点评；
  2. **围绕弱点追问**：抓模糊表述追问（"这个'比较低'到底低到哪儿？有没有上限？超过会怎样？"），并**故意埋一个错误复述**让学生纠正；
  3. **满三轮给总评**：有效作答满 3 轮才给总体评分（防止一轮敷衍过关）。
- 所有追问点都有教材出处支撑。
- 复用度：★★★★★（纯提示词 + 文本，成本最低、演示效果最好）

## 四、技术创新点拆解（这是评审最看重的部分，逐条给可复刻参数）

### 创新点 1 · 封闭语料的混合检索与逐句证据溯源
- **父子双层切分**："章节父块 — 段落子块"，实际规模 **56 个父块 / 117 个子块**。
- **双通道召回**：语义向量召回 + 关键词 **BM25** 召回。
- **归一化后加权融合**：**6.5 : 3.5**，即 λ（稀疏权重）= **0.35**。
- **命中子块自动回溯所属父块章节**，连同匹配度、出处编号一并返回。
- 设计意图（原话）："先按意思找，再按原词核对"，兼顾语义提问与术语原词（"Ac1""250 目"）。

### 创新点 2 · 会明确拒答的知识边界门控（★ 最有价值的一条）
- 对提问做 **IDF 加权关键词覆盖率**检查：**生僻词权重高、常见词权重低**，语料中不存在的词直接拉低覆盖率。
- 覆盖率 **< 阈值 τ = 0.50** → 触发拒答。
- 门控之上，提示词再约束"不得使用课程以外知识作答"，并要求标注"知识库未收录"。
- 实测：36 道探针（26 课内 / 10 课外）→ 课内覆盖率最低 **0.654**，课外最高 **0.361**，τ=0.50 落在中间形成 **0.293 的安全分离带**；课内全召回 26/26，课外全拒答 10/10，**零误判**。

### 创新点 3 · 教材数值约束的物理建模
- 45 钢回火温度—硬度曲线以教材实测数据为基准**逐点校验**。
- 开发中真实发现并修复的 bug：把已是 0.45%C 实测值的曲线**又做了一次含碳量修正**，导致 200℃ 回火硬度被误算为 53 HRC（教材 57–60），修正后恢复 59 HRC。
- 教材本身矛盾处（500℃ 处中温/高温回火区间重叠，40 vs 35 HRC）按 500℃ 归中温、500–510℃ 设过渡带，并在界面如实提示。
- 原则：**几何/数值量全部后端按公式算好下发，前端只渲染**。
- → 机械制图对应物：**公差查表与计算、三视图投影、剖面线生成、螺纹比例画法**，全部必须"算"不能"编"。

### 创新点 4 · 契约驱动的可插拔多模块架构（★ 工程上最该抄的）
- 每个模块遵守同一份**数据契约**：前端声明自己认领的**可视化数据类型**，后端工具产出对应结构的 **artifact**，外壳自动把"对话 / 工具调用 / 画布"编排起来。
- **新增模块只需按契约写一个目录，无需改动公共文件；模块之间不允许互相依赖。**
- **七类事件流**（对话过程逐帧下发）：`思考(thinking)`、`正文(text)`、`工具调用(tool_call)`、`工具结果(tool_result)`、`画布数据(canvas_data)`、`错误(error)`、`完成(done)`。
- → 这是我们做 8 个模块唯一可行的架构，否则会失控。

## 六、可借鉴 vs 需重构

### ✅ 直接借鉴（架构决策，不要重新发明）

5. "几何/数值全部后端算好下发、前端只渲染"的分工原则
6. 错题**六步诊改** + 6 类根因 + 溯源回原文
7. 费曼**逐句三色标注 + 满三轮才给分 + 故意埋错**

10. 单容器一体化交付 + 注册即用（学号/姓名自动建号）

### 🔧 必须重构（不能照搬）
1. **语料与切分**：它的 PDF/DOCX/PPTX 语料是纯文本可提取的；机械制图有**大量图**（三视图、剖视图、GB/T 表格），切分必须"文本块 + 图块"双模态，图要单独建索引（图号、图题、所属章节、可否回渲原页图）。
2. **3D 模块**：晶胞是参数化刚体；机械制图要 **STEP/IGES → OCCT → HLR 三视图**，还要剖切 + 剖面线。技术栈从"three.js 画球棍"升级为"three.js + OpenCascade.js(WASM) 求解 + 渲染"。
3. **视觉批改（全新）**：对标作品完全没有"用户上传手绘图并判错"的能力。需要新增：图像预处理 → 直线/圆弧检测 → 几何合规校验（线宽、线型、角度、粗糙度符号）→ VLM 语义复核 → 返回**坐标+错误码**。
4. **公差模块（全新）**：需要把 GB/T 1800 系列**结构化入库**并实现计算引擎，不能交给 LLM。
5. **知识图谱内容**：从材料学 6 星系换成机械制图"一核心两主线双分支"，节点数建议 ≥ 80（对标 71），关系 ≥ 110。
6. **问题图谱**（策划案漏写，必须补）：按"基础理解 → 识图分析 → 综合绘图/工艺"三层 + 布鲁姆标签。

## 七、给我们的 8 条硬结论

1. **不要找代码了**——包里没代码；但项目书的参数足够复刻，架构直接立项即可。
2. **先定"七类事件流 + 模块契约"再写任何业务代码**，这是 8 模块并行开发的前提。
3. **RAG 是地基，且它的参数可直接起步**：父子切分（父=节，子=段）、双通道、λ=0.35、τ=0.50，跑起来后再用自己的探针校准。
4. **探针评估法必须第一天就建**（26+10 的套路），否则"回答准确率"无法验收。
5. **凡是能算的绝不让模型背**：公差、投影、剖面线、螺纹参数、圆弧切点——全部后端确定性计算，这是"零幻觉"的唯一来源，也是评审最认的技术点。
6. **视觉批改是差异化最大、风险也最大的模块**：必须拆成"CV 几何校验（确定）+ VLM 语义复核（概率）"两段，且先定错误码表。
7. **数据规模走"少而精"**：16 条错题、21 张图、71 个节点就能撑起一份作品，但每一条都要是真的。
8. **诚实标注与边界拒答是加分项而不是减分项**——它当着评审的面承认"知识库未收录/未审核"，反而建立了可信度，我们应当照抄这个姿态。
