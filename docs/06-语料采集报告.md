### 2.2 需要特别说明的三点

1. **正文是自撰重组，不是原文搬运。** 16 篇正文全部由本次采集者按"读懂来源 → 打散 → 用自己的话重写"的流程撰写，没有整段复制、没有机器翻译腔。国家标准那 13 篇里，标准仅承担"事实来源与核验依据"的角色（标准号、名称、条款覆盖的主题），技术表述是为了教学可读性重写的，不是标准条文的转录。这一点在每篇 `license` 字段中已有交代。
2. **多数机械制图国标属于"采标"（采用 ISO 标准）**，公开系统对这类标准只提供题录信息、不提供正文阅读，因此本轮也不存在"把标准正文全文抓下来"的可能。凡是报告中出现的具体数值（如 0.85d、Ra 优先数系、IT7=25 μm 等），都是标准中的通用技术事实，用于教学解释，不构成对标准文本的复制。
3. **对外使用前必须做一次技术复核。** 标准会换版（例如 GB/T 4458.1 是 2002 版、GB/T 1182 是 2018 版），本报告采信的是 2026-11-07 在公开系统上查得的现行版本。产品正式上线前，建议由课程教师按现行标准逐条复核 13 篇 `standard` 文档中的数值与代号写法，尤其是表面结构、极限与配合、几何公差三篇（参数表与代号体系换版最频繁）。

### 8.3 准确性说明与需要教师复核的点

本轮以准确性优先，凡教材口径不一致、或本轮无原文可核的地方一律写明"以教材/标准为准"，没有编造数值。需要课程教师复核的具体点如下：

1. **圆柱倾斜截切的椭圆长轴 = d/sinθ**（θ 为截平面与轴线夹角，短轴恒为 d）。该式由投影几何推导得出、结论与教材一致，但部分教材用"长短轴比"或"截平面与端面夹角"来表述，措辞需按所用教材统一。
2. **圆锥五种截交的判据**用"截平面与轴线夹角 α、半锥角 β"表述（α=90° 圆；β<α<90° 椭圆；α=β 抛物线；0≤α<β 双曲线；过锥顶三角形）。有些教材改用"截平面与母线的夹角"表述，判据形式不同、结论相同，讲解时不要混用两套角度。
3. **相贯线简化画法的适用直径比**：教材差异最大的一处。有写"小径/大径 ≤ 0.3"，有写"直径相差 3 倍以上"，本轮只写"约三分之一左右及以下，具体界限以所用教材为准"，**未给出单一数值**，避免误导。
4. **相贯线的弯曲方向口诀**：各教材口诀表述互为镜像、容易写反。本轮刻意改用"三点定弧"的操作法（圆弧半径取大圆柱半径、圆心在小圆柱轴线上、通过两轮廓线端点与中间特殊点），**没有写方向口诀**，因为无原文可核，宁缺勿错。

**算例一（五环零件尺寸链）** 已知 A1=120(+0.08/0)、A2=30(0/−0.05)、A3=55(+0.03/−0.02)、A4=8(+0.02/−0.02)，A1 增环、A2/A3/A4 减环：

- 基本尺寸 A0 = 120−30−55−8 = **27**；ES0 = +0.08−[(−0.05)+(−0.02)+(−0.02)] = **+0.17**；EI0 = 0−[0+0.03+0.02] = **−0.05**
- 验算一（公差之和）：T0 = 0.17−(−0.05) = 0.22；ΣTi = 0.08+0.05+0.05+0.04 = 0.22 → **相等，通过**
- 验算二（极限尺寸路径）：120.08−29.95−54.98−7.98 = **27.17**；120.00−30.00−55.03−8.02 = **26.95** → 与 27(+0.17/−0.05) 的极限值完全一致，**通过**

**算例二（Φ30H8/f7 装配间隙链）** 孔 +0.033/0（增环）、轴 −0.020/−0.041（减环）：

- 间隙上偏差 = 0.033−(−0.041) = **+0.074**；下偏差 = 0−(−0.020) = **+0.020** → 间隙 **0.020～0.074 mm**，两偏差均为正，故为基孔制间隙配合
- 验算一（公差之和）：T0 = 0.054；ΣTi = 0.033+0.021 = 0.054 → **相等，通过**
- 验算二（极限尺寸路径）：30.033−29.959 = **0.074**；30.000−29.980 = **0.020** → 与公式结果完全一致，**通过**

两个算例的 `##` 末节都保留了"验算"行，且①的节内含"极限尺寸复核"、②的末节含"公差和 + 极限尺寸"双验算。
