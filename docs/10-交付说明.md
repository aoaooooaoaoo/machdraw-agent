## 2. 能力清单（9 模块 / 8 画布 / 11 工具）

| 模块（`state.MODULES`） | 能做什么 | 产出画布 | 主要工具 |
|---|---|---|---|
| `__global__` 全局对话 | 统一提问入口，自动路由到工具 | evidence | kb_search / kg_lookup / critical_calc / kinetics_calc / poison_calc |
| `kbrag` 教材与概念溯源 | 每句结论可回翻到教材·章节·页码 | evidence | kb_search / kg_lookup |
| `critical` 临界与扩散计算 | k∞、M²=L²+τ、B_m²/B_g²、k_eff、临界尺寸、反射层节省、不泄漏概率 | calc | critical_calc / spectrum_plot / kb_search |
| `kinetics` 动力学与反应性 | 点堆方程、倒时方程、周期、瞬发临界、反应性换算（pcm/$/Δk·k） | plot | kinetics_calc / reactivity_calc / spectrum_plot / kb_search |
| `poison` 燃耗与中毒 | 碘氙链、停堆碘坑、钐积累、燃耗深度、循环长度、换料 | plot | poison_calc / burnup_calc / kb_search |
| `concept` 概念辨析 | 成对图 + 差异点 + 随堂题（快群/热群、扩散/输运、正/负温度系数…） | comparison / quiz | comparison_pick / quiz_from_kb / kb_search |
| `graph` 知识图谱 | 焦点星图、前置依赖、易混淆对比、问题链（整页模式） | graph | kg_lookup / kb_search |
| `wrongbook` 错题与计算批改 | 六步诊改（原题→错误作答→根因→溯源→正解→避坑） | annotation / wrongbook | wrongbook_crud / kb_search / quiz_from_kb |
| `feynman` 费曼追问 | 逐句三色标注 + 追问 + 满 3 轮总评 + 故意埋错 | annotation | kb_search |

**七项硬设计**（复刻时最有价值的沉淀）：
1. **能算的绝不让模型背**：数值只经 `app/domain/` 7 个确定性引擎，模型只组织语言；
2. **三条降级不中断**：无 key → mock 抽取式；模型失败 → 回落 mock 并明示；证据字段 `.get` 兜底；
3. **每句结论可溯源**：证据卡带文档·章节·页码/chunk，越界问题走双门控拒答；
4. **双门控**：IDF 加权覆盖率 + 单块覆盖率，`gated = coverage<τ or chunk_cov<τ_chunk`；
5. **工具总线自注册**：新增工具 = 加一个文件（`TOOL = ToolSpec(...)`），三条硬校验；
6. **画布自注册**：新增画布 = 加 `features/<id>/index.ts` + 组件，壳不改；
7. **文档防漂移**：模块任务书由代码生成，`--check` 进 `verify_all`。

- 本工程**没有网络依赖**：无在线 embedding、无向量库、无外部 API（真实 LLM 除外，可 mock）；
- 索引/词表在本机确定性生成（hashing TF-IDF 用 `crc32`，无随机种子）；
- 唯一非确定项：SSE 帧数与耗时、教师端"最近错题"顺序（按时间）。
