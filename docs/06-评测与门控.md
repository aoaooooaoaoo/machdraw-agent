# 06 · 评测与门控（检索质量的可复算证据）

> 目的：回答两个问题——**该答的答不答得出来**、**不该答的会不会瞎答**。
> 所有数字可用 `apps/api/.venv/Scripts/python.exe eval/run.py` 复算；参数在 `apps/api/app/config.py`。

---

## 1. 评测口径

| 项 | 定义 |
|---|---|
| 探针集 | `eval/probes.jsonl` 54 题（40 课内 + 2 近邻 + 12 课外）；近邻=课程延伸但仍应收录（如"压水堆为什么用富集铀"） |
| 留出集 | `eval/probes_holdout.jsonl` 26 题（16 课内 + 1 近邻 + 9 课外），**不参与阈值标定**，用于报告泛化 |
| 判定 | `domain=="out"` → 必须被门控（拒答）；其余 → 必须不被门控（正常回答） |
| acc | 上述判定正确的比例 |
| 课内召回 | 课内/近邻题中未被门控的题数 / 总数 |
| 课外拒答 | 课外题中被门控的题数 / 总数 |
| 覆盖率 | IDF 加权的关键词覆盖率（生僻词权重大；语料外实义词按 OOV×1.2 计权；单字/虚词/通用提问词不计） |
| 单块覆盖率 | top10 召回块里，**单块**能吃下提问词的 IDF 加权比例（回答"是不是有一段就在讲这个"） |
| 门控规则 | `gated = coverage < τ 或 单块覆盖率 < τ_chunk` |

> 设计取向：**宁可拒答，不可编造**。所以 τ 与 τ_chunk 都按"课内最低分与课外最高分之间"取保守值。

---

## 2. 阈值标定（2026-11-09，语料 394 块 / 15 文档）

在 54 题标定集上扫 τ ∈ {0.30…0.55}、λ ∈ {0.30…0.55}，gating 实际由**单块覆盖率**主导：

| 指标 | 课内最低 | 课外最高 | 取阈 |
|---|---|---|---|
| coverage（IDF 加权） | 0.471 | 0.326 | **τ = 0.40** |
| 单块覆盖率 | 0.284 | 0.223 | **τ_chunk = 0.25** |

- 旧工程值（τ=0.55、τ_chunk=0.45）在本课程语料上会误拒 2 题（"压水堆能谱分几个能区""停堆碘坑"），因为新语料更口语化、术语更分散。
- λ（BM25 通道权重）在本语料上对门控无影响（单块覆盖率主导），保持 0.45 起步值。

---

## 3. 结果

| 集合 | acc | 课内召回 | 课外拒答 | 说明 |
|---|---|---|---|---|
| 标定集 54 题 | **1.000（54/54）** | 40/40 | 12/12 | 阈值即由该集选出，属**拟合值**，不作为泛化性能 |
| 留出集 26 题 | **0.962（25/26）** | 15/16 | 9/9 | 唯一失败：H10「燃耗达到多少算深燃耗？」coverage=0.396（差 0.004 过线） |
| 标定集 doc_hit | 40/40 | — | — | 课内题 top5 命中期望文档（按旧口径记录，不混入 acc） |

**诚实结论**：本项目在自建语料上的"课内可答、课外拒答"是成立的（留出集 96.2%）；但标定集 100% 是拟合，不能当泛化指标。H10 暴露的弱点是"燃耗深度"相关口语化提问（"深燃耗"不是课程术语），后续可在 KP 别名里补"深燃耗/高燃耗"。

## 4. 评测之外还有三层验证

评测只测"检索 + 门控"，不测工具与对话链路。完整验收还有：

1. **确定性引擎锚点**：`apps/api/tests/run_anchors.py`，68 条（教材例题/习题原答案 + 物理不变量），全绿；
2. **工具契约**：`apps/api/tests/check_tools.py`，11 个工具注册 + 6 个确定性工具的 calc/plot 画布字段；
3. **端到端**：`apps/api/tests/smoke.py`（对话 + 8 类画布）与 `scripts/e2e_check.py`（真实 HTTP + SSE + 前端托管）。

## 5. 如何复算 / 重标定

```powershell
cd D:\桌面\教学agent\核反应堆物理agent

# 1) 重建索引（改了 kb/ 之后必须）
\apps\api\.venv\Scripts\python.exe pipeline\build_kb.py

# 2) 标定集评测（默认 τ=0.40 / τ_chunk=0.25）
\apps\api\.venv\Scripts\python.exe eval\run.py

# 3) 留出集（不参与调参）
\apps\api\.venv\Scripts\python.exe eval\run.py --probes probes_holdout.jsonl

# 4) 扫参数
\apps\api\.venv\Scripts\python.exe eval\run.py --sweep

# 5) 换阈值（环境变量优先于代码默认值）
$env:RP_GATE_TAU="0.40"; $env:RP_GATE_TAU_CHUNK="0.25"
```

**重标定顺序**：改语料 → `build_kb.py` → `run.py --sweep` → 记下"课内min/课外max" → 把 τ 取在两者之间且偏保守（宁可拒答）→ 写回 `config.py` 与本文档。

## 6. 已知限制

- 探针只有 80 题（54+26），统计置信区间宽；扩到 200+ 题才适合做显著性结论。
- 门控按"关键词是否出现"判断，同义改写（" iodine pit " 的中文别称）可能误拒；目前靠 KP aliases 缓解。
- 只评"该不该答"，不评"答得对不对"——正确性由确定性引擎锚点与人工抽查保证（见 `docs/03`、`docs/09`）。
- 习题（role=exercise）默认不进知识问答索引，因此"出题"由 `quiz_from_kb` 单独处理，评测集不含出题类问题。
