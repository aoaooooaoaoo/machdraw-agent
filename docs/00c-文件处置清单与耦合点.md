# 00c · 文件级处置清单 / 机械制图耦合点 / 改造步骤

> 承接 `00-工程解剖与复刻蓝图.md`。本卷是**施工手册**：每个源文件一行，直接照做。
> 处置四分类：
> - **照搬** = 复制过来即可用（允许改品牌字符串常量）
> - **改名** = 目录/文件/记录换名，逻辑不动
> - **重写** = 逻辑或数据结构要改（保留骨架，内容替换）
> - **删除** = 不进入新工程
>
> 目标文件名一律以 `N/docs/SPEC-课程对象与数据契约.md`（SPEC）为准。
