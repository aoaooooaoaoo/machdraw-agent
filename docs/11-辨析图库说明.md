## 3. 每组讲什么 + 最容易画错的地方

### 3.1 `PAIR-POU-BAN-JUBU` 半剖 vs 局部剖

- **讲什么**：同样想"内外兼顾"，对称件用半剖（中心线为界、恰剖一半），非对称或要保留大部分外形时用局部剖（波浪线为界、只剖一块）。
- **几何要点**：A 以细点画线分界，左半剖视（法兰 + 筒壁两处剖面线）、右半只画外形；**视图半侧一根虚线都不画**。B 的平板用两段波浪线围出局部剖范围，**波浪线在孔口处断开**──孔是空腔，没有实体可断裂，所以波浪线不能横穿孔口。
- **最容易画错**：① 把半剖的分界线画成波浪线（国标明令只能是中心线）；② 波浪线一路画进孔内、或与轮廓线重合；③ 剖视侧的孔壁画了虚线（应画粗实线）；④ 忘了孔口的端面线在被剖到时要断开。

### 3.2 `PAIR-POU-QUAN-BAN` 全剖 vs 半剖（同一零件、同一剖切位置）

- **讲什么**：同一法兰套筒，全剖（A）外形全丢，半剖（B）留一半外形 —— 差别只在"剖多少、分不分界"。
- **几何要点**：两图共用同一套轮廓与孔位，A 是左右两半都画剖面线、两条孔壁都是粗实线；B 只有左半剖、右半外轮廓、顶面线画到中心线为止。
- **最容易画错**：① 全剖图的底部/顶部孔口处轮廓线不断开（通孔在剖切面上是空的）；② 半剖把中心线画成粗实线；③ 半剖视图半侧仍保留虚线，图面乱且重复表达。

### 3.3 `PAIR-DUANMIAN-POUSHI` 断面图 vs 剖视图（同一切割位置）

- **图示零件**：立柱 Ø64 + 肋板，立在方形底板上；水平剖切、向下投射。
- **讲什么**：A 只有断面形状（圆 + 肋），B 在断面之外还要画出剖切面后方可见的底板方形轮廓。
- **几何要点**：肋板宽度 16，肋板与圆柱面的交点按 `x = cx + √(R²−8²)` 精确求出（≈220.98），圆弧从 +14.48° 绕到 −14.48°，与肋板三条边严丝合缝。底板轮廓只画粗实线、**不画剖面线**。
- **最容易画错**：① 断面图里顺手把后面的底板轮廓也画了（那就成了剖视图）；② B 的底板轮廓也画上剖面线（剖面线只属于被切到的断面区域）；③ 肋板横向剖切时漏画剖面线（只有"纵向剖切肋板"才按不剖处理）。

### 3.4 `PAIR-JIEJIAO-XIANGUAN` 截交线 vs 相贯线

- **讲什么**：A 是平面与曲面相交（斜截圆柱得椭圆），B 是两曲面相交（小圆柱竖直相贯到大圆柱）。
- **几何要点**：A 画了主视图 + 俯视图，并画出截平面的点画线；主视图上那条**斜直线是椭圆的积聚投影**，不是倒角。B 的相贯线用国标允许的简化画法：**圆弧半径 = 大圆柱半径 40，圆心在小圆柱轴线上**，圆弧过两转向轮廓线交点 (158,148)/(222,148)、最低点 (190,164) —— 三点恰好共圆，与解析结果一致；另画了一条水平**辅助平面**及两个共有点，示意"辅助平面法"。
- **最容易画错**：① 把截交线画成空间曲线（截交线永远是平面图形）；② 相贯线弯向小圆柱一侧（应弯向大直径回转体轴线方向）；③ 简化圆弧半径取成小圆柱半径；④ 辅助面选得与曲面交出复杂曲线，作图做不下去。

### 3.5 `PAIR-XUSHI-SHIXIAN` 虚线 vs 粗实线（用错会怎样）

- **讲什么**：同一块带沉孔的板，A 用细虚线画不可见轮廓（正确），B 把同一组线画成粗实线（错误）。
- **几何要点**：两图**几何完全一样**，只差线型 —— 这样对比才干净。沉孔 Ø60 深到 y=176，Ø32 通孔到底；不可见轮廓共 5 条（两段沉孔壁 + 肩部 + 两段通孔壁）。
- **最容易画错**：① 把不可见轮廓描粗"为了看得清"；② 虚线用粗线宽（应 0.8，实线的一半）；③ 该用剖视图时硬拿虚线堆满图面。

### 3.6 `PAIR-DIYIJIAO-DISANJIAO` 第一角 vs 第三角

- **讲什么**：同一个台阶块（底板 60×40×10 + 凸台 30×20×20）、同样三个视图，只差视图摆在哪一侧。
- **几何要点**：A 第一角──俯视图在主视图**下方**、左视图在**右方**；B 第三角──俯视图在**上方**、左视图在**左方**。两图都满足长对正 / 高平齐 / 宽相等（主视图与俯视图同 x 范围、主视图与左视图同 y 范围、俯视图高 = 左视图宽 = 52）。左视图按"相贴不画线"规则画：底板与凸台左端面共面，所以那条交界线只在凸台宽度之外出现。
- **最容易画错**：① 第三角也把俯视图放下面（那是第一角）；② 左右视图"镜像"理解错（两种画法的视图内容相同，只是**位置**不同）；③ 把共面处的分界线画出来。

### 3.7 `PAIR-BANJING-ZHIJING` R 与 Ø 标注

- **讲什么**：同一块半圆头板 + Ø16 通孔，A 圆弧注 R20、整圆注 Ø16（正确）；B 圆弧注 Ø40、整圆注 R8（错误）。
- **几何要点**：A 的 R 尺寸线**从圆心引出、只画一个箭头**指向圆弧；Ø 尺寸线**通过圆心、两端箭头**顶住圆周。B 的圆弧改用引出线 + 错符号，两处错误各配一个人工画的红叉（不用 ✗ 字形，避免字体缺字）。
- **最容易画错**：① 只要看到圆弧就注 Ø；② 整圆注 R；③ R 尺寸两端都画箭头；④ 尺寸线不通过圆心 —— 标注"不成立"而非"不好看"。
- 说明：国标符号实际写作 **Ø**（GB/T 4458.4），任务书里的"Φ"是同一符号的手写体；本图库统一用 Ø，与 `FIG-POUSHI-BAN` 等既有图一致。

### 3.8 `PAIR-CHICUNLIAN-FENGBI` 封闭尺寸链 vs 留开口

- **讲什么**：同一根三段轴（30 / 40 / 50），A 把总长 120 也注出来 → 四个尺寸首尾相接成封闭链；B 不注总长，留作开口环。
- **几何要点**：两图三段长度、台阶高度完全一致，尺寸线画法也一致（连续标注），**唯一变量是 B 少了总长那一条**。总长标号 ① 在 B 图指向的就是"本该有、但故意不注"的位置。
- **最容易画错**：① 以为"注得越全越规范"，把总长和分段全注；② 留开口时删掉了关键装配尺寸（应该删最次要、自然形成的那一环）；③ 把"尺寸链封闭"与"尺寸重复"混为一谈（前者是回路，后者是同尺寸注两次）。

### 3.9 `PAIR-LUOWEN-NEIWAI` 内螺纹 vs 外螺纹画法

- **讲什么**：同一公称直径 M40，外螺纹牙顶在大径画粗、牙底在小径（0.85d）画细；内螺纹剖视正好互换：小径 D1 画粗、大径 D 画细。
- **几何要点**：A 杆 d=80、牙底 68（=0.85d）；B 剖视块的剖面线**只画到牙顶粗实线为止**，细的牙底线落在剖面区域内部；内螺纹两端面在孔口处断开。
- **最容易画错**：① 大小径的粗细线画反；② 剖面线一路画过牙底线；③ 螺纹终止线用细线或漏画；④ 端视图的小径圆画成整圆（应约 3/4 圈）。

### 3.10 `PAIR-POUMAINXIAN-FANGXIANG` 相邻零件剖面线方向

- **讲什么**：座 + 衬套同时被剖，A 两个零件都画 45°（同向，错）；B 座 45°、套 135°（反向，对）。
- **几何要点**：座外廓 110…270×150…230，镗孔 Ø56；套外径 Ø56、内孔 Ø28，两端各伸出 12。**座的左右端面只画到配合面为止**，不能一条竖线画通（那里是套的壁，不是座的材料）；配合面只画一条线。
- **最容易画错**：① 相邻零件剖面线同向（分不清零件）；② 端面线画通，把套的壁切断；③ 配合面画成两条线（只有有间隙才画两条）。

## 5. 已知不足（哪些差异点画得不够清楚）

诚实列出，便于后续迭代或让 lead 决定是否返工：

1. **`PAIR-DUANMIAN-POUSHI` 的 ①②**：断面图（A）里"没有底板轮廓"这件事，只能把标号指向**空白处**，初看像标号错位。这是"以有比无"类差异图的固有困难；已在图例里写明"A 没有"。
2. **`PAIR-JIEJIAO-XIANGUAN` 的三条差异**：来源 / 形状 / 求法都是概念性的，图面上只能都指向同一条交线，三条标号挤在一条线附近，区分度明显不如几何类差异。A 图那条斜直线不加俯视图很容易被看成倒角，我加了俯视图，但仍需文字提示"这是椭圆的积聚投影"。
3. **`PAIR-DIYIJIAO-DISANJIAO` 没画识别符号**：国标两国都有"投影法识别符号"（截头圆锥台），画上会让"这是第几角"一眼可判。我没画（形状与三视图挤在一格里太满）。另外 B 图 ③ 的引线是从 12px 的视图缝里穿过去的，偏挤。
4. **`PAIR-BANJING-ZHIJING` 的"≤180°/＞180°"分界**：这是 R/Ø 取舍的根本判据，但它在图上**看不出来**，只能靠图例那句口诀。另外 B 图的两个红叉是我手画的（两段斜线），不是国标符号。
5. **`PAIR-LUOWEN-NEIWAI` 的两条线太近**：0.85d 的比例决定了牙底线只比牙顶线内缩 6px，缩到手机宽度时会糊成一条粗线；这是比例画法的固有属性，不便放大（放大会失真）。另外**没画端视图**（外螺纹大径整圆粗、小径 3/4 圈细），而端视图恰是这组最易错的地方，只在图例里写了一行。
6. **`PAIR-POUMAINXIAN-FANGXIANG` 的"同向"错误不够刺眼**：A 图看上去仍然很整齐，缩略图尺寸下两个零件的辨识差异不够强烈。另外只有两个零件，没体现"三个以上零件时依次错开"。
7. **`PAIR-CHICUNLIAN-FENGBI` 的"公差挤压"是概念性的**：图上只能靠"多注了一个总长"来表达，看不出"互相挤压"。若给尺寸加上公差（30±0.1 之类）矛盾会更具体，但会超出辨析图的信息量，暂未加。
8. **第 1、2 组的 A 侧共用同一个法兰套筒**：便于横向对照，但两张图连看会显得重复；如果前端把 10 张并排铺开，观感上像"同一张图出现两次"。
9. **文字不自动换行**：版面固定 760×420，图例按 11px / 10.5px 控制在一行约 60 字以内。若前端改字号或换字体（尤其用等宽字体），长行可能溢出右边界。
10. **波浪线是"拟手绘"而非真手绘**：用正弦 + 相位漂移生成，放大能看出规律，与国标"徒手断裂线"的随意感仍有差距。
11. **`d₁` / `D₁` 的下标字符**：Chrome 正常；但用 cairosvg 批量转 PNG 时（cairo 无字体回退）会渲染成豆腐块。若后续要用 PNG 出 PPT，建议先把这两个符号替换成 `d1`/`D1` 或改用 `<tspan>` 下标。

## 6. 复现与改动入口

| 要改什么 | 改哪里 |
|---|---|
| 某组几何/引线/图例文字 | `pairs/_tools/pairs_defs.py` 里对应的 `pair_xxx()` |
| 版面常量（标题 y、图形区上下界、图例行距） | `pairs/_tools/pairkit.py` 顶部 `Y_TITLE…LEG_DY` |
| 线型/线宽/配色 | `pairs/_tools/pairkit.py` 的 `STROKE` / `INK` / `RED` |
| 校验规则（图上限定 90 图元等） | `pairs/_tools/build_pairs.py` 的 `validate_svg()` |

改完跑一次 `build_pairs.py --png` 即重写 SVG + `pairs.jsonl` + QA 图；再跑 `make_preview.py` 刷新预览页。
`_qa/` 下都是可再生的检查物（PNG / 预览页 / 校验输出），不属于产品资源。
