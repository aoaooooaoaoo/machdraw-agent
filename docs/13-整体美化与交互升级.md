> 避免 Tailwind/Radix 的构建改造与包体积风险。

## 2. 新增的交互（可点、可键盘）

| 交互 | 怎么用 | 实现 |
|---|---|---|
| **命令面板** | `Ctrl/⌘ + K` 或顶栏「搜索」 | `shell/CommandPalette.tsx`：搜索模块、直接发预设问题、开始新会话、复制运行信息、打开教师端；↑↓ 选择 / Enter 执行 / Esc 关闭 |
| **消息操作** | 悬停助手回答 → 「复制」「重新回答」；悬停自己的问题 → 复制 | `MessageItem.tsx`：复制走 `lib/ui.ts` 的 `copyText`，重新回答用同一问题再发一次 |
| **新会话** | 输入框左下 ↻ 按钮 | store 新增 `clearSession`，只清当前模块，不动其它模块 |
| **回到底部** | 上翻历史后右下浮动按钮 | `ChatPanel.tsx` 记录是否贴底 |
| **画布全屏** | 画布右上「全屏查看 / 退出全屏（Esc）」 | `CanvasPanel.tsx`，CSS `position: fixed` 覆盖层 |
| **画布骨架屏** | 提问后、artifact 到达前自动出现 | shimmer 骨架 + "正在检索并计算结果" |
| **9 模块快捷网格** | 对话空态直接点模块切换 | 比"只看左栏"更直观，尤其窄屏 |
| **Toast 反馈** | 复制、新会话、错误等 | `lib/ui.ts` 订阅式 toast + `shell/Toast.tsx`（2.6s 自动消失） |
| **快捷键辅助** | 输入框提示、空态提示、命令面板底部图例 | `Ctrl K` 搜索、`Ctrl /` 聚焦输入、`Esc` 关闭 |
| **焦点可见** | Tab 键导航 | 全局 `:focus-visible` 蓝色 ring |

## 3. 视觉美化（不换框架）

- **设计令牌**：圆角 12px、两级阴影、`--ring` 焦点圈、更柔和的页面底色（蓝/紫极淡径向渐变）。
- **顶栏**：毛玻璃 + 品牌渐变图标；新增搜索入口（带 `Ctrl K` kbd）。
- **左导航**：模块项卡片化，hover 浮起、active 带浅蓝底与投影、图标高亮。
- **对话**：用户气泡渐变蓝；助手 Markdown 排版按讲义标准（段落/列表/表格/引用/行内代码/代码块/链接）；示例 chip 浮起；空态增加 9 模块网格。
- **输入区**：卡片化 + `:focus-within` 双层高亮；字数提示；快捷键提示。
- **画布**：与对话区同一套卡片语言；骨架屏；全屏。
- **命令面板 / Toast**：模糊遮罩、圆角面板、kbd 键帽、滑入动画。
- **可访问性**：`prefers-reduced-motion` 关闭动画；按钮 aria-label；toast `aria-live`。
- **响应式**：≤1180 收窄左右栏、隐藏搜索文字；≤980 隐藏次要 badges；≤760 隐藏模型 chip。

## 4. 顺手修的一个路由 bug

知识库问答里"缓发中子为什么重要"这类**概念题**原来会因为命中关键词"缓发"被路由到 `kinetics_calc`，工具缺反应性 ρ 而失败，白挂一张工具卡。
现在 `_plan` 增加**计算意图判定**：只有题面里出现数值/单位，或"多少/计算/求/等于"等问法，或当前就在计算类模块时，才走确定性工具。
回归：
- `什么是缓发中子？为什么重要？` → `kb_search`（不再误调）
- `阶跃引入0.2$反应性，反应堆周期是多少？` → `kinetics_calc`
- `k∞=1.06，M2=180cm2 的裸堆临界曲率是多少？` → `critical_calc`
