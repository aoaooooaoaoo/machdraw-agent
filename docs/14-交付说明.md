## 二、怎么跑起来

### 方式 A：本机直接跑（推荐，已验证）

```powershell
# 1) 起后端（已含前端构建产物，直接托管）
cd apps\api
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8077

# 2) 打开
#    学生端  http://127.0.0.1:8077/
#    教师端  http://127.0.0.1:8077/admin
#    接口文档 http://127.0.0.1:8077/docs
```

**不需要 API Key**。默认 `MW_LLM_PROVIDER=mock` 走"本地证据抽取 + 模板作答"，
与参考作品的"本地资料检索，未调用大模型"模式等价。想接真实模型：

```powershell
$env:MW_LLM_PROVIDER="deepseek"; $env:MW_LLM_API_KEY="sk-..."
```

模型调用失败会自动降级回本地模式并在回答里注明，不会中断对话。

### 方式 B：Docker（✅ 已实机验证）

```powershell
$env:HOST_PORT="8078"          # 8077 默认给本机开发服务，容器建议用 8078
docker compose up -d --build
```

**实测（2026-11-07）**：镜像 434 MB，容器 `Up (healthy)`，
`/api/health`（566 块 / 169 节点 / 279 边 / 11 工具）、`/`、`/admin`、`/api/chat`（真问一句出
`three_view` + `evidence`）全部通过。

> 曾经起不来的根因与修复全过程见 `docs/16`：`~/.docker/daemon.json` 带 UTF-8 BOM → 后端启动即崩；
> 另外镜像源里有个 2018 年就停服的 `registry.docker-cn.com` 也会让构建 EOF。

### 方式 C：前端开发模式

```powershell
cd apps\web; npm install; npm run dev    # 5173，代理到 8077
```

### 改了知识库之后


## 五、四个自研核心（技术看点）

1. **极简 CSG + 隐藏线消除（HLR）**：长方体/棱柱求并差 → 锐边 ∪ 轮廓线 → 射线遮挡判定。
   第一角三个视图的方向由 `right = d × u` 推导，**摆位规则不是凑的**。
   踩过并解决"并集伪接缝线"（L 形块由两块拼成时多出一条不存在的棱）。
2. **真剖切**：半空间裁剪凸多面体 → 切面多边形 → 45° 剖面线并按孔洞断开；
   全剖/半剖/局部剖三种，局部剖的波浪线是正弦扰动边界。
3. **可判定找茬**：把"AI 判图"拆成"识别"与"几何比对"两段，本系统实现后者——
   漏画/多画/虚实线/位置/方向五类错误全部可算、可复核。
4. **双门控**：关键词覆盖率（语料层面）+ 单块覆盖率（证据层面）。
   参考作品的单门限在语料放大 10 倍后失效（课外题覆盖率一度到 1.0），这是关键改动。

## 七、已知限制（照实写）

2. **held-out 只有 38 题**：差 1 题就是 2.6 个百分点，样本偏小，建议扩到 80–100。
3. **题目是 OCR 题面**：有错字（已过滤 56 条质量过低的，仍不干净），题卡上有提示。
4. **手绘找茬没有画板**：现在只能"系统改错图、学生找茬"，或从程序提交线段；
   学生自己画需要前端加一块 canvas 输入。
5. **三视图只支持 8 个预置模型**：几何内核只认长方体与棱柱，不支持任意 STEP；
   要支持学生上传任意模型需换 OCCT。
6. **剖切面只支持轴对齐**（X/Y/Z=常数）：阶梯剖、旋转剖、斜剖未实现。
7. **肋板"纵剖不画剖面线"这条国标特例未实现**（现有模型里没有肋板结构）。
8. **棱柱 n=32 近似圆柱**：三视图里圆会画成 32 边形，放大能看出来。
9. **20 条知识条目 + 6 处教材口径不一致需人工复核**（清单在 `docs/07` §6、`docs/06` §8.3），
   本系统刻意"没编数值"，把不确定的都标出来了。
