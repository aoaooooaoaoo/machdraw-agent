## 一、尺寸链的组成与环的判别

尺寸链是指在零件加工或部件装配过程中，相互联系并按一定顺序排列成封闭形式的一组尺寸。这组尺寸中的每一个都称为"环"。尺寸链的封闭性是指各环首尾相接、形成回路；一旦某一环自然形成、不再由加工直接控制，这条链就闭合了。

环分三类。封闭环（记作 A0）是在加工或装配过程中最后自然形成的尺寸，也就是"间接得到"的尺寸；组成环是直接控制、影响封闭环的尺寸。组成环又按影响方向分为两类：增环（记为 A⁺）是其余环不变时，本身增大使封闭环也增大的环；减环（记为 A⁻）是本身增大反而使封闭环减小的环。增减环的判别可用回路法：从封闭环一端出发，沿回路依次画出各组成环的箭头，与封闭环箭头方向相同的是减环，相反的是增环；不同教材表述互为镜像，最稳妥的做法是用极值法公式回代校验一次。

判别增环减环是尺寸链计算的第一步，也最容易出错。一个实用检查法是取极值试算：假设某个组成环取最大值、其余取基本尺寸，看封闭环是变大还是变小，变大即为增环。这种方法不必记箭头规则，凭定义即可判断，适合在考试中快速验算。

## 二、封闭环与组成环的计算关系（极值法）

极值法是最基本、工程上最常用的计算方法，它的出发点是最坏情况也能满足要求。封闭环的基本尺寸等于所有增环基本尺寸之和减去所有减环基本尺寸之和：A0 = ΣA⁺ − ΣA⁻。这一步只做基本尺寸的代数运算，不含公差。

偏差的计算遵循"增环同向、减环反向"：封闭环的上偏差等于所有增环上偏差之和减去所有减环下偏差之和，即 ES0 = ΣES⁺ − ΣEI⁻；封闭环的下偏差等于所有增环下偏差之和减去所有减环上偏差之和，即 EI0 = ΣEI⁺ − ΣES⁻。公差的计算最简单，封闭环公差等于所有组成环公差之和：T0 = ΣTi。

最后一条关系导出一个重要结论：封闭环的公差必然大于或等于任何一个组成环的公差，也就是说封闭环的精度是整条链中最低的。这个结论有直接的工程含义——凡是精度要求高的尺寸，都不能让它成为封闭环，而必须直接标注、直接控制。理解这一点，就理解了尺寸链存在的意义：它把"哪些尺寸直接控制、哪些尺寸自然形成"这件事说清楚了。

## 三、图样上为什么不能出现封闭尺寸链

如果一张零件图上，同一方向的所有尺寸首尾相接、全部标注出来，就构成了一条封闭尺寸链。这在图样上是不允许的，原因有两个层面。

第一是工艺层面。封闭尺寸链中的最后一环必然是自然形成的封闭环，它的公差等于其余各环公差之和。加工时各环的误差会全部累积到这个环上，谁都控制不了，结果很可能超出功能要求。第二是逻辑层面。标注尺寸的目的是给加工和检验提供依据，一条链上若每环都标了公差，则这些公差之间存在必须成立的约束关系，一旦某个尺寸因工艺原因调整，其他尺寸的公差就得跟着改，图样失去稳定性。

工程上的处理办法是"留开口"：故意把尺寸链中的某一环省去不注，或者只注基本尺寸而不注公差（有的标准体系允许写成参考尺寸，常见做法是加圆括号，具体写法以所用标准为准），使整条链在某处断开。开口环应选精度要求最低、最不重要、最容易由工艺自然保证的那一环。这样处理后，其余各环的公差都能独立给定，加工误差由开口环吸收，关键尺寸的精度就有了保障。

## 四、算例：阶梯轴的长度尺寸链

设一根阶梯轴，总长 A1 = 40（上偏差 +0.05，下偏差 0），台阶段长 A2 = 15（上偏差 0，下偏差 −0.10），求剩余段长 A0 及其公差。

第一步判断环的性质：A0 由总长与台阶长"相减"得到，若加工时先保证总长、再车出台阶，则 A0 是最后自然形成的，为封闭环；A1 增大时 A0 增大，故 A1 为增环；A2 增大时 A0 减小，故 A2 为减环。

第二步算基本尺寸：A0 = A1 − A2 = 40 − 15 = 25 mm。第三步算偏差：ES0 = ES(A1) − EI(A2) = +0.05 − (−0.10) = +0.15 mm；EI0 = EI(A1) − ES(A2) = 0 − 0 = 0。故 A0 = 25（+0.15 / 0）mm。

第四步校验公差：T0 = 0.15 − 0 = 0.15 mm，而 T(A1) + T(A2) = 0.05 + 0.10 = 0.15 mm，两者相等，说明计算正确。这个结果同时暴露了问题：剩余段 25 mm 的公差被放大到 0.15 mm，接近名义尺寸的 0.6%，若该段是要与别的零件配合的功能尺寸，精度显然不够。正确做法是把 25 改为直接标注并给定合理公差，让 15 成为开口环（不注公差或注参考尺寸），由加工自然保证。这就是"留开口"在实际图样中的落地方式。
