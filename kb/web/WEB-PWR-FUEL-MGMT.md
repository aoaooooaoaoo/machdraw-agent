## 一、燃料管理要解决什么问题

反应堆一次装料要运行十几个月，期间燃料不断消耗、裂变产物不断积累，剩余反应性一路下降。燃料管理的任务，就是在满足安全设计准则与运行限制的前提下，根据电力需求和核燃料资源约束，为电厂一系列运行循环给出"装什么料、装在哪、什么时候换、换多少"的决策方案。

教材把燃料管理分成两大部分：一是**堆芯燃料管理策略与换料方案的确定**，二是**初始堆芯与换料堆芯的核设计**。前者是"定策略"，后者是"做计算、出参数、作评价"。策略部分的决策变量包括：一批换料量 N 或批料数 n、循环长度 T、新料富集度、循环功率水平、燃料组件在堆芯的装载方案、控制毒物的布置方案。这些变量之间强耦合，因此实际工程中要借助多循环、多维度的计算来优化。

## 二、几个必须分清的时间与燃耗概念

| 概念 | 定义 | 常用单位 | 容易混淆之处 |
|---|---|---|---|
| 循环长度 | 一次装料后能满功率运行的时间 | EFPD（等效满功率天） | 与"日历时间"不同，受负荷因子影响 |
| 换料周期 | 两次停堆换料之间的时间间隔 | 月 | 满功率运行时等于循环长度 |
| 堆芯寿期 | 从装料运行到 k_eff 降至 1 的满功率时间 | 月/EFPD | 与单循环长度不是一回事 |
| 燃耗深度 | 单位质量燃料释放的能量 | MWd/tU | 是"能量/质量"，不是时间 |
| 卸料燃耗深度 | 卸出时的燃耗 | MWd/tU | 分平均卸料燃耗与最大卸料燃耗 |
| 批料数 n | n = N_T/N（组件总数/每次更换数） | 无量纲 | 压水堆常用 3 批 |

循环按特性分为**初始循环**（全部新料）、**过渡循环**（第 2 循环到平衡循环之间）、**平衡循环**（各循环性能参数相同）、**扰动循环**（因燃料破损等原因偏离平衡）。平衡循环是理论上的目标循环，工程上大多数循环都在向它靠拢。

## 三、多循环与单循环：两种粒度的计算

燃料管理的计算被有意解耦成两层。**多循环燃料管理**用"点堆反应性模型"：把每批料看成一个整体，用相对功率份额 f_i 描述各批料对堆芯功率的贡献，再用线性反应性模型（LRM）近似"批料反应性随燃耗线性下降"，从而快速算出循环长度、富集度、批料数与卸料燃耗之间的关系。它不考虑组件在堆芯中的具体位置，只考虑"批"。

**单循环燃料管理**则要精确到组件与栅元：给定富集度、批料数和循环长度后，确定燃料与可燃毒物在堆芯中的具体布置，做二维/三维中子学计算，给出功率分布、功率峰因子、临界硼浓度、控制棒价值等。它需要组件程序提供随燃耗、硼浓度、功率、慢化剂密度、氙浓度变化的少群截面拟合关系。

两层之间的关系是迭代的：多循环定"批"的策略，单循环验证并修正具体布置，结果再反馈给多循环。

## 四、批料数与富集度：一组很有用的定性结论

教材用平衡循环的解析关系给出了几个可以直接用于判断的结论：

1. **批料数增加，卸料燃耗提高、循环初剩余反应性降低**。因为每次换料量减少，堆内易裂变核总量下降；组件在堆内停留时间变长，燃耗自然加深。
2. **保持新料富集度不变时，循环燃耗随批料数增加而减少**；要保持循环燃耗不变，则需要提高富集度。教材给出一个典型估算：压水堆由 3 批换料改为 4 批、保持循环燃耗不变，新料富集度约需从 3% 提高到 3.5%，而卸料燃耗约为 3 批时的 4/3。
3. **批料数不是越多越好**：批料数增加会提高卸料燃耗、降低对反应性控制系统的要求，但换料更频繁、成本上升；商用轻水堆一般取 3 批左右，压水堆最典型的是 3 批年换料或 18 个月换料。
4. **卸料燃耗受燃料材料限制**：锆合金包壳 + UO₂ 芯块的燃料，卸料燃耗限值约 40 000～50 000 MWd/tU，超过限值燃料破损风险显著上升。

## 五、安全与经济的平衡

燃料管理的最终目标是降低燃料循环成本，但所有优化都必须在安全限值内进行：最大卸料燃耗不得超过燃料组件限值；功率峰因子必须满足热工安全要求；停堆裕量、反应性系数、控制棒价值等必须满足设计准则；每次换料后还要按最终安全分析报告（FSAR）做换料堆芯安全评价。

因此，燃料管理不是单纯的"数学优化"，而是"安全约束下的经济性优化"。理解这一点，才能明白为什么压水堆普遍采用 3 批换料、18 个月循环、低泄漏装料这些看似固定的工程选择。
