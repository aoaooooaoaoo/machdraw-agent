## 一、基本术语：尺寸、偏差、公差

GB/T 1800.1—2020《产品几何技术规范(GPS) 线性尺寸公差 ISO 代号体系 第1部分：公差、偏差和配合的基础》建立了一整套术语。基本尺寸是设计给定的尺寸；实际尺寸是测量得到的尺寸；极限尺寸分上极限尺寸和下极限尺寸，实际尺寸必须落在两者之间。偏差是某一尺寸减其基本尺寸所得的代数差，上偏差 ES/es、下偏差 EI/ei 分别对应上、下极限尺寸与基本尺寸之差。

公差是上极限尺寸减下极限尺寸之差，也等于上偏差减下偏差，永远是正数。公差带由公差大小和公差带位置两部分决定：大小由标准公差等级确定，分 IT01 至 IT18 共 20 级，数字越大公差越宽、精度越低；位置由基本偏差确定，基本偏差是靠近零线的那一条偏差。这套"公差等级 + 基本偏差"的编码方式，就是 H7、k6 这类代号的全部含义。

## 二、配合与基准制

基本尺寸相同的孔与轴装配在一起，其公差带的相互关系决定了配合性质。孔的公差带完全在轴的公差带之上时为间隙配合，完全在下方时为过盈配合，相互交叠时为过渡配合。配合的松紧不是由单个零件决定的，而是由孔、轴公差带的相对位置决定的。

为了减少刀具和量具规格，标准规定了两种基准制。基孔制以孔为基准，孔的基本偏差代号为 H，即孔的下偏差为零，通过改变轴的基本偏差获得各种配合，字母 a 至 h 为间隙配合、j 至 n 多为过渡配合、p 至 zc 为过盈配合。基轴制以轴为基准，轴的基本偏差代号为 h，即轴的上偏差为零。一般情况下优先采用基孔制，因为加工孔的刀具和量具规格化收益更大；当同一根轴需要与多个孔配合且松紧要求各不相同时，改用基轴制更合理。

## 三、H7/k6 的读法

配合代号写作"基本尺寸 + 孔公差带代号 / 轴公差带代号"，如 Φ50H7/k6。读法是：基本尺寸 Φ50 mm，基孔制，孔的公差带为 H7，轴的公差带为 k6，属于过渡配合。计算时先查表得标准公差值，IT7 在 30 至 50 mm 尺寸段为 25 μm，IT6 为 16 μm，故孔 H7 为 Φ50(+0.025 / 0)；轴 k6 的基本偏差为下偏差 ei = +0.002 mm，上偏差 es = +0.002 + 0.016 = +0.018 mm。

配合性质的定量判断由此得出：最大间隙等于孔上偏差减轴下偏差，即 0.025 − 0.002 = 0.023 mm；最大过盈等于轴上偏差减孔下偏差，即 0.018 − 0 = 0.018 mm。既有间隙又可能出现过盈，故为过渡配合。做题时只要把握"孔的上偏差、下偏差与轴的上偏差、下偏差交叉相减"这一条，就不会把最大间隙和最大过盈算反。若计算结果中最大间隙与最大过盈同时为负值，说明配合性质判断有误，应回到公差带图核对两者的相对位置。

## 四、图样上的标注与常见错误

在装配图上标注配合代号，如 Φ50H7/k6；在零件图上标注孔、轴的公差带代号或直接标注极限偏差数值，如 Φ50(+0.025 / 0)。两种标注方式不能混用到同一个尺寸上，也不能既注代号又注偏差而数值不一致。常见错误包括：把基孔制与基轴制的基准代号写反；把过渡配合误判为间隙配合；计算最大过盈时用反了公式；以及在零件图上标注了装配图才用的配合代号。

理解这部分内容的关键，是把"公差带图"当作核心工具而不是背表格。画出零线、孔轴两条公差带，配合性质、最大间隙、最大过盈都能从图上一眼看出。所有计算公式其实都是公差带图上下边界之差的文字表述，记图比记公式更稳。
