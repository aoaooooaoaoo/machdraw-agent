## 一、一次换料大修要做什么

压水堆除个别在线换料的堆型外，都是"运行一个循环 → 停堆换料 → 再运行"。换料的典型流程是：停堆冷却 → 卸出需要更换的（或全部）燃料组件至乏燃料水池 → 按换料方案在堆内倒料 → 装入新燃料组件 → 临界逼近与启动 → 启动物理试验 → 重新并网。

教材把换料装料分为两种形式：一种是把整个堆芯组件全部卸出，再按方案依次装回可继续使用的旧组件与新组件；另一种是只卸出不再使用的组件，其余旧组件在堆内按方案移动，最后装入新组件。前者操作简单、便于检查，是目前多数核电厂的做法；后者倒料次数少、但堆内操作更精细。

## 二、两种典型装料方案

| 项目 | Out-In（外内装料） | 低泄漏装料（In-Out/低泄漏） |
|---|---|---|
| 新料位置 | 堆芯外区 | 堆芯内区 |
| 旧料位置 | 堆芯内区，新旧交替分散 | 燃耗较深的旧料放在最外缘 |
| 优点 | 展平全堆通量分布、降低整体功率峰与局部功率峰 | 大幅减少中子泄漏、提高中子经济性、延长寿期；显著降低压力容器快中子辐照 |
| 缺点 | 新料在外导致泄漏严重、浪费中子，压力容器辐照大 | 功率峰较高，需较多可燃毒物压制，燃料组件反应性随燃耗呈非线性 |
| 工程地位 | 20 世纪 80 年代曾广泛采用 | 目前世界上多数压水堆采用 |

低泄漏装料的收益非常可观：在保持循环长度与新料数量不变的情况下，新料富集度可比 Out-In 方案降低约 5%～10%；更重要的是快中子泄漏减少，使压力容器的中子辐照显著下降，寿命可从约 40 年延长到约 60 年，其经济价值远超"功率峰偏高"的代价。

## 三、批料数与循环长度怎么选

压水堆普遍采用 3 批换料：每次更换约 1/3 的组件，组件在堆内停留 3 个循环。教材用平衡循环的解析关系给出：保持循环燃耗不变，由 3 批改为 4 批需要把新料富集度从约 3% 提高到约 3.5%，而卸料燃耗约为 3 批时的 4/3；若保持富集度不变，则循环燃耗会下降、卸料燃耗上升。批料数增加能提高卸料燃耗、降低循环初剩余反应性，但换料更频繁、成本更高，因此要综合优化。

循环长度的选择是经济性与能源需求的平衡：轻水堆普遍选 12 个月或 18 个月，一个重要原因是把换料大修安排在用电低谷（春季或秋季）。18 个月循环可减少大修次数、提高可用率，但要求更高的富集度与更强的反应性控制能力。

## 四、换料不是"装回去就行"：换料堆芯安全评价

每次换料后的堆芯与最终安全分析报告（FSAR）中的分析工况不可能完全一致，因此必须做换料堆芯安全评价。教材介绍的基本方法是**安全边界分析**：只要与事故有关的关键安全参数都保守地落在 FSAR 安全分析的边界限值内，则 FSAR 的结论对换料堆芯仍然适用；若参数超出边界，就要对相关事故重新分析，必要时修改技术规格书、运行规程甚至重新设计装载方案。

评价工作包括两部分：一是对关键安全参数（功率分布、反应性控制参数、动力学参数、热工水力参数等）做系统验证；二是对超限参数对应的事故做再评价。教材列出的典型事故包括：不可控硼稀释事故、提棒事故、落棒事故、弹棒事故和主蒸汽管道断裂事故。这些问题大多与反应性直接相关，因此换料设计的物理计算必须给出可靠的停堆裕量、棒价值与反应性系数。

## 五、乏燃料与后端

卸出的乏燃料先在乏燃料水池冷却 5～10 年，再送后处理厂处理或长期贮存。燃耗越深，乏燃料中剩余 ²³⁵U 越少、²³⁹Pu 越多，后处理的经济性与防扩散要求也越高。因此换料策略不仅影响堆芯物理，也影响整个核燃料循环的后端安排。
