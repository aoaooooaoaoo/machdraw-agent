## 一、术语标准的定位与使用方式

GB/T 4960 系列是我国核科学技术领域的术语类国家标准，按专业方向分部分编排；每个部分只负责给出该方向的术语名称、英文对应词与定义，不规定具体堆型的运行参数，也不代替设计/安全类标准。它解决的是"同一个词在不同教材、不同单位里说法不一致"的问题，因此适合作为课程问答中"名词解释"类问题的权威出处。

使用时有三个要点。第一，**先确认词条归属**：核物理与核化学、裂变反应堆、核燃料与核燃料循环、辐射防护等方向分属不同部分，查错部分会找不到词条。第二，**以标准原文定义为准**：本整理只做课程高频术语的归纳与比对，不逐条复制定义。第三，**区分标准术语与教材习惯用语**：教材为便于教学会使用"中子注量率""堆芯寿期"等工程化简称，标准中往往有更严格的对应名称，答题时以课程口径为主、引用时注明标准号。

> 说明：GB/T 4960 各部分的具体编号、年份与名称需人工复核（离线环境无法查证标准现行版本），课程引用时请以现行有效版本为准。

## 二、课程核心术语一览

下表按课程顺序整理高频术语，定义要点为课程口径的概括，英文名按核工程通行写法给出（以标准原文为准）。

| 术语 | 英文（通行写法） | 定义要点 | 课程出处 |
|---|---|---|---|
| 核反应堆 | nuclear reactor | 能以可控方式实现自持链式裂变（或聚变）反应的装置 | 第一章 1.1 |
| 中子注量率（中子通量密度） | neutron fluence rate / flux density | 单位体积内全部中子在单位时间内穿行路程的总和，记作 Φ | 第二章 2.2 |
| 微观截面 | microscopic cross section | 一个入射中子与一个靶核发生某类反应的概率度量，记作 σ | 第二章 2.2.1 |
| 宏观截面 | macroscopic cross section | 中子与单位体积内全部靶核发生某类反应的概率度量，Σ = Nσ，量纲为长度的倒数 | 第二章 2.2.2 |
| 平均自由程 | mean free path | 中子与核发生首次碰撞前穿行的平均距离，λ = 1/Σ | 第二章 2.2.3 |
| 核反应率 | reaction rate | 单位时间、单位体积内中子与核发生作用的总次数，R = ΣΦ | 第二章 2.2.4 |
| 有效增殖因子 | effective multiplication factor | 一代中子中由裂变产生并留在系统内、可供下一代使用的中子数，记作 k_eff | 第三章 3.1 |
| 无限介质增殖因子 | infinite multiplication factor | 不考虑泄漏时的增殖因子，记作 k∞ | 第三章 3.1 |
| 反应性 | reactivity | 增殖因子偏离临界的相对量，ρ = (k_eff − 1)/k_eff | 第三章 3.1 |
| 临界 / 超临界 / 次临界 | critical / supercritical / subcritical | ρ = 0 / ρ > 0 / ρ < 0 | 第三章 3.1 |
| 剩余反应性 | excess reactivity | 堆芯内不含任何控制毒物时的反应性 | 第六章 6.2 |
| 停堆深度 | shutdown margin | 全部控制毒物投入后达到的最大负反应性 | 第七章 7.4 |
| 燃耗深度 | burnup | 装入堆芯的单位质量燃料所释放的能量，常用 MWd/tU | 第六章 6.4 |
| 堆芯寿期 | core lifetime | 从装料运行到 k_eff 降至 1 的满功率运行时间 | 第六章 6.4 |
| 循环长度 | cycle length | 一次装料后能满功率运行的时间，常用 EFPD 表示 | 第九章 9.2 |
| 碘坑 | iodine pit | 停堆后 ¹³⁵Xe 先增后减造成的剩余反应性凹陷 | 第六章 6.2.2 |
| 多普勒展宽 | Doppler broadening | 靶核热运动使共振峰展宽、峰值下降的现象 | 第二章 2.4 |
| 缓发中子 | delayed neutron | 先驱核衰变后延迟发射的中子，份额记作 β | 第八章 8.2 |
| 点堆动力学 | point reactor kinetics | 忽略空间变量、把堆芯视为一个点的动力学模型 | 第八章 8.2 |
| 外推距离 | extrapolation distance | 按通量切线外推到零处所对应的距离，d ≈ 0.7104λ_tr | 第四章 4.2 |
| 徙动面积 | migration area | 慢化面积与扩散面积之和，M² = L_s² + L²（也写作 τ + L²，τ 为热中子年龄） | 第三章 3.4.3 |
| 群常数 | group constant | 按能群对截面做通量加权平均得到的等效截面 | 第四章 4.3 |
| 并群 | energy group collapsing | 由多群（约 70–300 群）加权合并为少群（2–4 群） | 第四章 4.3.4 |
| 反应性温度系数 | temperature coefficient of reactivity | 温度变化 1 K 引起的反应性变化，常用 pcm/K | 第七章 7.1 |
| 空泡系数 | void coefficient | 空泡份额变化 1% 引起的反应性变化 | 第七章 7.2 |
| 硼微分价值 | differential boron worth | 单位硼浓度变化引起的反应性变化，常用 pcm/ppm | 第七章 7.4 |

## 三、最易混淆的几组术语

| 容易混用的两词 | 区别要点 | 常见错误 |
|---|---|---|
| 中子注量率 Φ 与中子流密度 J | Φ 是标量（单位体积内中子路程总和的速率）；J 是矢量（单位时间穿过单位面积的净中子数） | 把 J 的单位写成 m⁻²·s⁻¹ 当成 Φ，或反过来 |
| k_eff 与 k∞ | k_eff 含泄漏；k∞ 是无限大介质、无泄漏 | 用 k∞ 直接判断实际堆是否临界 |
| 反应性 ρ 与增殖因子 k | ρ 是 k 偏离 1 的相对量，量纲为一、数值很小；k 本身是比值 | 把 ρ = k − 1 当成定义（仅当 k≈1 时近似） |
| 燃耗深度、循环长度、堆芯寿期 | 燃耗深度是"能量/质量"；循环长度与寿期是"时间" | 把卸料燃耗深度与循环长度混为一谈 |
| 控制棒积分价值与微分价值 | 积分价值是某棒位以下的累计反应性；微分价值是单位插入距离的变化率 | 用微分价值的最大值代替总价值 |
| 剩余反应性 与 停堆深度 | 剩余反应性不含控制毒物；停堆深度是全部控制毒物投入后的负反应性 | 把两者都叫"停堆反应性" |

## 四、使用注意事项

1. **英文名不要自造**：标准术语的英文对应词是固定写法，课程答题若需要英文，优先用标准原文，其次用教材写法。
2. **符号体系要统一**：本课程用 σ、Σ、Φ、k_eff、ρ、β、λ、T、M² 等符号；不同教材对反应性有 ρ、Δk/k 两种写法，转换时注意定义差异。
3. **术语与量纲一起查**：查"平均自由程"时同时确认 λ = 1/Σ 的量纲与单位（SI 用 m，工程常用 cm）。
4. **引用格式**：正文引用时写明标准号与部分号，例如"GB/T 4960 系列（核科学技术术语）"，具体部分号与年份需人工复核后再引用。
