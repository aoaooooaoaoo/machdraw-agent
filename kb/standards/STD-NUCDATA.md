## 一、核数据的层次：从实验到堆芯计算

反应堆物理计算的输入是截面等核数据，其形成链条一般分为四级：

1. **实验测量数据库**：如 EXFOR，收录各实验室测量的截面、角分布、裂变中子数等原始数据；
2. **评价核数据库**：对实验数据做评价、拟合与理论计算，给出一套自洽、完整的推荐值，如美国的 ENDF/B、日本的 JENDL、中国的 CENDL、欧洲的 JEFF；
3. **处理与群常数库**：用 NJOY 一类程序把评价库加工成连续能量截面或群常数（含共振自屏、多普勒展宽），供组件程序使用；
4. **组件/堆芯程序**：产生少群均匀化截面，最终进入扩散或输运计算。

教材第 2 章 2.3.4 节把评价库的内容概括为六类：不同能量中子与各核素各类反应的微观截面；弹性/非弹性散射的角分布；裂变中子能谱与每次裂变的平均中子数；共振核素在不同稀释截面、不同温度下的共振积分参数；各裂变核素全部裂变产物的产额；反应放出中子、质子、γ 与 α 粒子的能量分布与角分布概率。教材附录 3 的截面表即注明取自 ENDF/B-VII.0。

## 二、ENDF-6 格式的组织方式

ENDF-6 是评价核数据的通用交换格式，一份文件由若干"材料（MAT）"组成，每个 MAT 再按"文件号 MF + 反应号 MT"组织成二维结构：

| 记号 | 含义 | 内容 |
|---|---|---|
| MF1 | 描述性数据 | 材料目录、能区、温度、评价信息 |
| MF2 | 共振参数 | 分辨/未分辨共振的能级、宽度、道参数 |
| MF3 | 截面 | 各 MT 的截面随能量变化（含本底截面） |
| MF4 | 角分布 | 弹性/非弹性散射的角分布 |
| MF5 | 能量分布 | 次级中子、γ 的能量谱 |
| MF6/MF7 | 能-角关联、热散射 | 热中子散射律 S(α,β)（如水中 H） |
| MF33 | 协方差 | 截面不确定度与相关系数，用于不确定度传播 |

常用 MT 号：MT1 总截面、MT2 弹性散射、MT3 非弹（总）、MT4 非弹性散射、MT16 (n,2n)、MT18 裂变、MT102 辐射俘获 (n,γ)。记录类型为 HEAD/CONT/TAB1/LIST，按行分段排列，读取时必须按格式手册解析而不能按文本近似。

## 三、主要评价库与版本

| 数据库 | 主要版本（通行说法） | 说明 |
|---|---|---|
| ENDF/B | VI、VII.0（2006）、VII.1（2011）、VIII.0（2018） | 教材附录采用 VII.0 |
| JENDL | 4.0 及后续 | 日本评价库，热散射与结构材料数据较完整 |
| CENDL | 3.x 系列 | 中国评价库，国内程序常用 |
| JEFF | 3.x 系列 | 欧洲评价库 |
| BROND | 3.x 系列 | 俄罗斯评价库 |

各库的截面在共振区、热区与高能区存在差异，尤其是 ²³⁸U 共振积分、²³⁵U 裂变中子数 ν、水的热散射律等关键量。工程上必须记录"用了哪个库、哪个版本、哪个温度"，否则结果不可复现。

## 四、从评价库到群常数：共振自屏与并群

评价库给的是"无限稀释"点截面，堆芯内中子通量在共振峰处被强烈压低，必须做**共振自屏**修正。常用做法是引入背景截面 σ₀（由栅元几何与材料组成决定），再用等价原理或子群方法求有效共振积分；温度升高时按多普勒效应做展宽（BROADR 类处理），使共振峰变宽变矮。

处理流程可概括为：**点截面重建（RECONR）→ 多普勒展宽（BROADR）→ 共振自屏/群化（GROUPR 或组件程序）→ 生成群常数**。教材第 5 章指出工程上采用两步均匀化：先对栅元做多群（约 70～300 群）输运计算，再并群到中能群（约 15～30 群），最后按少群（2～4 群）截面求解堆芯扩散方程。并群的原则是"通量加权、守恒反应率"，不能简单算术平均。

## 五、使用注意与不确定度

1. **基准工况**：截面表通常给 0.025 3 eV（2 200 m/s）、300 K 的参考值；跨温度、跨能区使用必须插值或做自屏修正。
2. **数据不确定度**：评价库的协方差（MF33）用于传播到 k_eff、功率分布等堆芯参数；工程设计中常对计算结果作保守修正（教材第 10 章提到控制棒价值按计算值的 90% 取值）。
3. **不要让程序替你选库**：同一题目换库后 k_eff 可能差数百 pcm，因此教学与工程都必须写明数据来源。
4. **禁止凭记忆写数值**：²³⁵U 的 ν、σ_f、σ_γ 等数值随版本变化，引用时必须给库名与版本。
